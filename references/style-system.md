# 3D visual style system

## D — 日常世界：3D冷写实

默认前缀：

> 16:9横画幅，24fps，高品质3D中国动画电影，国漫半写实人物比例，真实中国人面部结构，稳定精细的面部绑定、自然眨眼和克制口型；PBR皮肤、发丝、布料与生活物件材质，低饱和蓝灰色调，约4300K冷色实景光，35–50mm自然镜头语言，电影级全局光照、自然景深与运动模糊。

日常世界约束：

- 使用真实当代中国建筑、出租屋、道路和实景光源。
- 保持三维动画质感，不做真人摄影，也不做二维插画。
- 魔法保持缺席。剧情关键的超自然道具最多出现一处克制暖色高光，不改变整场风格。
- 避免水墨山形、古代幻想建筑、金色法术轨迹、赛博霓虹、美颜磨皮和夸张动漫表情。

## S — 山海订单：3D暖金水墨美术

默认前缀：

> 16:9横画幅，24fps，高品质3D中国动画电影，国漫半写实人物比例，真实中国人面部结构，稳定面部绑定；PBR皮肤、发丝、布料、旧木、铜器和雨水材质，电影级全局光照、体积雾与景深。山海水墨仅作为三维环境的色彩、材质微纹理、体积墨雾、负空间与灯光语言：深墨绿和炭黑底色，克制暖金轮廓光，极少朱砂点色，宣纸纤维只作为表面细节，墨迹以有体积的雾和粒子呈现。

山海世界约束：

- 人物始终是完整立体3D角色，与日常世界保持同一张脸、同一体型和同一套基础服装。
- 金色只服务于灯笼、路线、记忆边缘、道具提示或人物轮廓。
- 使用中国志怪轮廓、木、纸、旧铜、石与云雾，不使用西方奇幻铠甲和怪物语言。
- 避免平面水墨人物、剪纸人、静态概念图、仙侠游戏UI、赛博霓虹、彩虹传送门、爆炸法术和华丽堆砌。

## T — 世界切换

优先生成两个独立片段：

1. 日常片段结束在黑暗、隧道阴影、手机光、驶过的车辆、水花、闪电或关闭的门上。
2. 山海片段从匹配的构图、运动方向和声音尾巴开始。

只有用户明确要求镜内变形时才使用 `T`。保持机位、焦段和主体位置不变，只允许一个渐进变化，例如墙面材质从水泥逐层纸化。

## 参考图默认声明

每个使用图片参考的镜头都要明确其作用。仓库默认使用：

> 人物/场景设计参考@图片N，仅参考脸型特征、发型轮廓、服装结构、道具、配色或空间关系；不作为首帧，不复制参考图的二维笔触、平面质感、排版和原镜头构图；重新构建为统一的高品质3D国漫角色与PBR三维场景。

若用户明确指定 `R-IDENTITY`、`R-FIRST` 或 `R-STYLE`，再替换相应作用，不得擅自升级参考强度。

## 统一3D稳定性后缀

> 保持角色身份、年龄、脸型、发型、服装、身体比例和随身道具一致；保持左右位置、视线方向、天气、光线和空间关系连续。动作自然有重量，面部绑定稳定，头发、衣料、雨水、烟雾与物体接触符合物理规律。禁止二维插画、纸片人、静态设定页、真人摄影、跑脸、换装、重复人物、多余肢体、畸形手、物体穿模、背景跳变、闪烁、抖动、分屏、拼贴、模型生成字幕、可读文字、品牌标志和水印。

只保留与该镜头风险相关的禁止项，不要机械复制整段造成提示词噪声。

## 角色锚点模板

> `[角色名]`：剧情年龄和身份；脸型与关键辨识点；发型；固定服装；固定道具；动作质感；3D材质重点。

示例：

> `姜禾`：25岁中国女性外卖骑手；疲惫但警觉的眼睛、右眉浅疤；潮湿短黑发；青灰旧骑手服与旧红围巾；动作实用克制；PBR皮肤保持自然毛孔，湿发成束但不油亮。

每个镜头只重复当前景别真正看得见、且容易漂移的锚点。
