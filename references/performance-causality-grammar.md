# 表演因果与情绪控制语法

本文件吸收李一帆《一个公式控制所有AI视频角色表情》的核心方法，并将其接入导演研读、三层表演和Seedance提示词压缩流程。课程提出“人物情绪 = 表情细节 + 肢体动作 + 说话语气”，并强调情绪需要真实发生原因。本Skill进一步区分导演层原因与模型层可见触发，避免解释性文字导致穿帮。

## 1. 导演层完整公式

研读剧本时使用：

> `触发事件 → 人物如何理解 → 此刻目标 → 采用策略/社会性伪装 → 动作 + 表情 + 微表情 + 语气 → 镜尾残留`

- 触发事件：刚刚发生、被看见、被听见或被触碰的事实。
- 人物理解：人物认为这件事意味着什么，同一事件对不同人物意义不同。
- 此刻目标：人物希望对方、环境或自己下一秒发生什么。
- 策略/伪装：讨好、回避、威胁、试探、压制、撒娇、装镇定等。
- 表演结果：可见动作、主表情、二至四个微表情信号和可听语气。
- 镜尾残留：情绪没有凭空消失，留下可供下一镜继承的呼吸、视线、姿态或手部压力。

这套因果由剧本决定。不要为了展示“演技”给角色增加剧本没有的情绪转折。

## 2. 模型层精简公式

真正送入视觉生成模型时使用：

> `可见/可听触发 + 主动作 + 主表情或伪装 + 2–4个微表情 + 可见结束状态`

声音字段另写：

> `说话目标 + 呼吸 + 音量 + 语速 + 音高走向 + 停顿/咬字`

导演层的“人物理解”和“目标”用于选择表演，不必逐字塞进视觉载荷。只有当原因本身在镜头中可见或可听时，才写入画面或声音。

错误：

> 她因为想起医院里去世的母亲而紧张地抬头看手术灯。

若母亲和手术灯不在当前近景，模型可能把它们错误生成进画面。

正确：

> 画外心电监护声突然加快，她的眼神先抬向画外上方，半拍后才抬头；下唇收紧，右手指尖压住床单，呼吸由浅变停。

## 3. 情绪不是表情贴纸

不要写：`她非常开心，露出开心的表情`。

按时间写变化：

1. 基线：触发前的身体和注意力状态。
2. 触发：对方动作、声音、道具变化或上一镜结果。
3. 处理延迟：眼睛通常先于头部，呼吸通常先于语言。
4. 外泄/控制：嘴角、眉间、下颌、手指或重心泄露真实反应；角色也可能立刻压住它。
5. 残留：镜尾仍保留一个未完成信号。

真实感来自微小延迟、信号不完全同步和人物试图控制自己，而不是把眼睛、眉毛、嘴和身体同时推到最大幅度。

## 4. 三层表演与语气

### 动作

写身体真正做了什么：起点、路径、接触、受力、结果。动作必须服务目标。

### 表情

写观众第一眼读到的主情绪，或人物故意展示的社会性伪装。

### 微表情

选择二至四个能说明强度、转折或潜台词的信号：

- 眼神：凝视、短暂避开、扫视、焦点迟疑。
- 眼睑：变窄、轻颤、快速眨眼、停眨。
- 眉间：短促收紧、单侧抬起、压低。
- 嘴与下颌：嘴角压住、下唇颤动、吞咽、咬紧。
- 呼吸：吸气停顿、浅快、缓慢释放、说话前漏气。
- 手与身体：指腹加压、肩膀下沉、重心后撤、脚尖转向出口。

### 语气

不要只写“生气地说”。选择真正能听见的参数：

- 呼吸：稳、急、说话前吸气、尾句漏气。
- 音量：压低、正常、突然拔高、逐渐减弱。
- 语速：快、慢、先快后停、关键词放慢。
- 音高走向：尾音上扬、下压、单调维持、突然断裂。
- 咬字与停顿：含混、咬紧、关键词重读、半拍停顿。

语气、身体与微表情默认同源。若人物撒谎或伪装，明确写出冲突，例如：`声音温柔平稳；右手指腹持续压紧杯壁，回答前视线短暂避开`。

## 5. 同一句台词的不同表演

台词：`走开。`

### 撒娇拒绝

- 触发：对方靠近逗她。
- 目标：口头拒绝，但不希望对方真的离开。
- 动作：肩膀轻推对方一下，身体只转开四分之一，脚没有后退。
- 表情：故作不满。
- 微表情：推开后立刻偷看对方，嘴角压住笑意，眼睑放松。
- 语气：音量偏低，首字轻，尾音略拖长并上扬。

### 嫌弃驱赶

- 触发：对方越过私人距离。
- 目标：立即拉开距离。
- 动作：上身后撤，手掌阻挡，脚尖转向出口。
- 表情：明显排斥。
- 微表情：鼻翼短收，眼睑压窄，下颌向后收紧。
- 语气：短、硬、无拖尾，第二字下压。

同一句话的区别来自目标、身体是否真正离开、微表情和语气，而不是给“撒娇”或“嫌弃”重复加权。

## 6. 多人场景的反应层级

- 当前主体完成完整因果链。
- 对手先给可见/可听触发，再做低幅度回应，不能同时抢戏。
- 背景人物只保留一个群体反应方向，例如停下动作、转头或交换眼神。
- 反应镜头必须新增判断、决定或关系变化；只有“听见了”但没有新信息时可以不切。

## 7. 常见失败与修正

| 失败 | 原因 | 修正 |
|---|---|---|
| 表情像贴纸 | 只有情绪名，没有触发和动作 | 写可见触发、处理延迟和动作结果 |
| 五官同时夸张 | 堆满面部信号 | 只留2–4个信号并按时间先后出现 |
| 情绪突然跳变 | 缺少基线或触发 | 从上一镜状态接入，给半拍处理时间 |
| 角色只动脸不动身体 | 目标没有转译成策略 | 增加重心、接触、手部或距离变化 |
| 原因导致画面穿帮 | 把不可见解释塞进视觉提示词 | 原因留在导演层，只写可见/可听证据 |
| 台词与身体割裂 | 语气独立设计 | 用同一目标统一动作、表情、微表情和声音 |
| 每个人都在演 | 未设置主体层级 | 主体完整表演，对手克制，背景降幅 |

## 8. 输出前检查

- 情绪来自剧本中的真实触发，不是凭空添加。
- 已明确人物此刻目标与策略。
- 视觉载荷只包含镜头可见或可听的因果证据。
- 动作、表情、微表情和语气彼此一致，或明确说明伪装冲突。
- 微表情只有二至四个，并按合理顺序发生。
- 镜尾保留可继承的呼吸、视线、姿态、接触或手部状态。
