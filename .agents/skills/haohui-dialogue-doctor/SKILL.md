# 浩辉台词诊断

中文调用名：**浩辉台词诊断**。内部调用标识：`$haohui-dialogue-doctor`。

## 必读参考

1. 阅读 [references/dialogue-dimensions.md](references/dialogue-dimensions.md)。
2. 台词将进入视频生成、配音或表演提示时，再阅读 [references/performance-timing.md](references/performance-timing.md)。

## 边界

- 保留剧情事实、人物关系、信息顺序和场景目的，除非用户明确授权改写。
- 每条修改都要给原因；没有证据和理由的润色不输出。
- 先判断是否该说，再判断怎么说。能由动作、目光、道具或停顿表达的信息，不强塞解释性对白。
- 用户只要求诊断时，不直接替换原台词；用户要求精修时，给原句、改写和原因。

## 工作方式

1. 建立角色语言指纹：身份、教育、年代、地域、欲望、禁用词、句长和语气习惯。
2. 逐句判断该句改变了什么：信息、立场、关系、情绪或下一步行动。
3. 使用七维框架诊断，优先修角色辨识度、潜台词和冲突推进，再考虑金句。
4. 对强情绪台词补齐动作、表情、微表情和声音，但不堆满所有面部细节。
5. 估算自然朗读时长和停顿压力；无法在目标时长内自然说完时，建议精简、拆连续单元或调整片段时长，不要求演员机械加速。
6. 检查改写后是否仍符合人物知识边界和类型年代。

## 默认输出

1. `台词总体病灶`
2. `角色语言指纹`
3. `逐句诊断`：原句 / 判断 / 改写（若授权）/ 理由
4. `自然语速与表演风险`
5. `建议保留的有效台词`
6. `交给导演或配音的表演说明`
