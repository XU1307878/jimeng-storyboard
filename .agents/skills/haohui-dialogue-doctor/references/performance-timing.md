# 台词时长与三层表演

## 自然语速

优先使用用户给出的语速标准。没有标准时只做区间估计，不把估计冒充平台硬限制。估算时计入停顿、呼吸、哭腔、犹豫、动作打断和多人抢话。

英文项目如果用户指定每秒约3个单词，就按该标准计算；中文不能直接套用英文单词速度。

## 表演因果

按以下顺序设计：

`触发 → 角色判断 → 当下目标 → 社交面具/策略 → 动作 + 表情 + 微表情 + 声音 → 余留状态`

- 动作：姿态、重心、手部接触、行动和结束姿势；
- 表情：观众能读懂的主要情绪或角色故意展示的面具；
- 微表情：选择2–4项，如视线停顿、眨眼、眉间变化、嘴角控制、下颌收紧、吞咽、呼吸或抓握压力；
- 声音：音量、速度、音高走向、气息、停顿和咬字。

情绪变化必须有可见或可听触发。微表情应按顺序泄露，不要同时堆成静态“情绪脸”。
