# 台词七维诊断

1. **角色辨识度**：遮住角色名还能否认出说话者；检查词汇、句长、句式、文化层和禁用词。
2. **潜台词**：字面内容、真实意图和社交策略是否存在有效差异。
3. **冲突推进**：说完后信息、立场、关系、情绪或行动是否改变；连续三句无变化通常需要删改。
4. **类型语感**：语言是否符合年代、职业、地区和作品类型，避免现代词误入古装或所有人同一播音腔。
5. **信息效率**：一句最好同时承担两项以上功能；双方都知道的信息不应专门说给观众。
6. **节奏与可朗读性**：长短句、停顿、呼吸和语气词是否自然，避免整段同长度或过度书面。
7. **记忆点**：只在人物和冲突成立后考虑可传播句；一场一至三句足够，不能人人说金句。

优先级：角色辨识度、潜台词、冲突推进 > 类型语感、信息效率、朗读节奏 > 记忆点。
