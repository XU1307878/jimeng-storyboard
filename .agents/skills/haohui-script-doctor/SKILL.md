# 浩辉剧本会诊

中文调用名：**浩辉剧本会诊**。内部调用标识：`$haohui-script-doctor`。

## 使用边界

- 必须有完整剧本、大纲、单集、单场或足以支撑单点判断的梗概。
- 只诊断用户指定范围，不擅自重写剧情；用户要求修改时可以给修改方案，正式重写交给剧本创作/改编 Skill。
- 不承诺“必爆、必火、一定能拍”，只判断当前证据下的优势、病灶、风险和测试方向。
- 每个关键判断必须引用剧本事实、场次、台词或结构节点；禁止“整体不错、可以加强”式空话。

## 必读参考

1. 阅读 [references/evidence-diagnosis.md](references/evidence-diagnosis.md)。
2. 短视频、竖屏剧、爆款开头或完播优化任务，再阅读 [references/platform-rhythm-audit.md](references/platform-rhythm-audit.md)。

## 工作方式

1. 明确会诊范围：全剧、单集、单场或单点。
2. 复述作品目标、受众、平台和不可改事实；缺失但不影响判断时标为暂定。
3. 建立证据表：原文/事实 → 判断 → 影响。
4. 分别检查故事承诺、因果、人物欲望与阻力、信息控制、冲突升级、反转证据、情绪兑现、结尾义务和生产难点。
5. 按高、中、低排序问题。高优先级必须是会连锁破坏后续的病灶。
6. 每个问题提供可执行的修改方向，并写清保留项，避免为了修一处破坏人物或伏笔。
7. 若问题主要在对白，转交 `$haohui-dialogue-doctor`；若剧本已定稿并要设计镜头，转交 `$haohui-director`。

## 默认输出

1. `会诊结论`
2. `作品承诺与当前完成度`
3. `证据化问题清单`
4. `人物与关系诊断`
5. `结构与节奏诊断`
6. `平台节奏体检`（适用时）
7. `修改优先级与保留项`
8. `下一步建议`
