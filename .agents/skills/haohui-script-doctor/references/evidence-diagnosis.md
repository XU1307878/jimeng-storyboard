# 证据化剧本诊断

## 核心检查

- 故事承诺：开场向观众承诺了什么体验，后续是否兑现；
- 主角发动机：当下欲望、阻力、选择与代价是否持续制造事件；
- 因果：关键转折是否由此前行动和证据造成；
- 人物知识边界：谁知道什么、何时知道、观众何时知道；
- 冲突推进：每场是否改变信息、立场、关系、目标或风险；
- 反转公平性：反转前有可回看的证据，反转后能重新解释旧信息；
- 情绪兑现：压抑、期待或悬念是否获得相称回报；
- 结尾义务：本集或本场提出的问题是否完成、升级或形成有效钩子；
- 可制作性：是否存在不必要的场景、角色、特效、群演或连续性风险。

## 问题卡

每个重要问题写成：

```text
问题：
证据：剧本中的具体事实、场次或台词
影响：它如何伤害理解、情绪、人物或完播
优先级：高 / 中 / 低
修改方向：改变什么，不直接代写整剧
必须保留：人物、伏笔、主题或因果中的不可损失项
```

高优先级常见于：主角没有可持续目标、关键行为无动机、反转无证据、观众无法理解基本空间或人物关系、核心情绪没有兑现。语言润色通常不能盖过这些结构病灶。

## 多视角使用

可以分别采用制片、类型编剧、核心受众、平台编辑或表演视角，但这些只是分析维度，不必角色扮演。若各视角结论相同，要检查是否遗漏真实分歧；最终由证据而非身份权威决定优先级。
