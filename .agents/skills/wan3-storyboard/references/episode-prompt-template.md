# 剧集提示词九层模板（拆镜 → 最终生视频提示词）

> 用途：拆镜完成后，把分镜表转成可直接提交 wan3.0 的最终提示词。本文件是**文档骨架**——规定一条多镜头提示词由哪几层组成、每层写什么；每层内部的语义写法仍以 [`wan3-formulas.md`](wan3-formulas.md) 与 SKILL.md §2 六层结构为准。

---

## 何时用

拆镜产出分镜表后 → 走本模板输出最终提示词。适用条件：多镜头、多角色、跨空间交错叙事的剧集段落。单镜头或纯情绪特写不需要这套骨架，直接按 SKILL.md §2 写。

---

## 九层结构

| # | 层 | 作用 | 是否逐镜重复 |
|---|---|---|---|
| 1 | 【全局设定】 | 画质 / 画幅 / 字幕 / 音频 / 其他（一致性+物理+口型+空间+表演）/ 基调 | 否 |
| 2 | 【角色设定】 | 每个角色一行，声明 @图片N 严格以本图为唯一依据（脸/发式/服装均由图承载，不复述） | 否 |
| 3 | 【配音资产】 | 每个开口角色一条 @音频N | 否 |
| 4 | 【场景资产】 | 每个空间一张环境锚点图 | 否 |
| 5 | 【道具资产】 | 关键道具图 + 四视图声明 | 否 |
| 6 | 【场景与空间说明】 | 叙事结构 + 空间参照 @图片N（陈设以图为准，不复述） + 角色站位姿态 + 道具状态时间线 | 否 |
| 7 | 【镜N】 | 逐镜七字段块 | 是 |
| 8 | 【镜N·结束状态】 | 仅最后一镜，收束姿态 | 否 |
| 9 | 收尾重申段 | 一致性 + 空间切换规则 + 表演约束 | 否 |

第 1-6 层写一次不逐镜复述，第 9 层在末尾重申——利用模型对首尾位置更敏感的特性锁一致性。

## 逐镜七字段规格

标题行：`【镜N】景别+运镜+前景特征（起s-止s）`

| 字段 | 内容 | 要点 |
|---|---|---|
| 画面内容 | 前景遮挡物 → 主体 @引用+动作 → 表演物理描述 → 开口/静默动作 → **"背景虚化，保持低存在感"** | 前景遮挡须过 `shot-language.md` §八 三检验；大特写填满画幅时写"不设前景遮挡"并说明画面层次由什么构成；**道具在画面里可见就必须写，即使不承担前景遮挡**（§九） |
| 光影 | 光源方向 + 主体受光 + 暗部色 | 同空间连续镜可写"与镜N一致"做继承，省 token |
| 声音设计 | 具体声源列表 + 底噪 | 无台词镜也要指定声源，防模型自行生成对白 |
| 台词 | `无` 或 `[@图片N（角色）·@音频M]（语气）：台词原文` | 语气收进括号；VO 镜须同时写明入画角色嘴唇闭合 |
| 风格锚点 | 焦段 + 光圈(f/2.0-f/2.8) + 景深 + 主光与暗部 + 可选修饰 + 细胶片颗粒 | 焦段序列相邻不重复 |
| 衔接 | 下一镜去向 | **必填**。同空间用"顺切/运镜衔接"，跨空间用"快切至X"，见 SKILL.md §4 转场纪律 |
| 结束状态 | 仅最后一镜 | 收束姿态，为下一段提供落脚点 |

## 拆镜 → 提示词转换规则

| 拆镜写法 | 提示词写法 | 逻辑 |
|---|---|---|
| 克莱尔-浅粉色晨袍（服装全称 token） | @图片1（克莱尔） | token → 图片引用；**服装外观不复述**，由参考图承载 |
| 会议室-落地窗+城市天际线 / 宽大黑色皮椅 | 参照 @图片3（陈设以图为准） / "办公椅"（中性化） | **拆镜里的环境元素与家具材质描述一律剥离**：参考图有的不复述，参考图没有的直接删，与参考图矛盾的中性化 |
| （微表情库：压迫感审视） | 面部肌肉紧绷 | **标签全部丢弃，只留物理描述** |
| 斯坦尼康平移推轨 | 平稳横移 | 专业术语 → 通俗说法 |
| 50mm 标准定焦 | 50mm f/2.0 浅景深 | 补光圈 + 景深 |
| [2.5s]（相对时长） | （2s-4.5s）（绝对时间码） | 相对 → 绝对，段内无缝隙连续 |
| 角色（状态/语气）："台词" + 后置形容句 | [@图片N·@音频M]（语气）：台词 | 语气收进括号 + 绑定音频资产 |
| 全片限定（一段） | 全局设定 + 收尾重申 | 拆成头尾两处 |

**最关键一条：微表情标签在提示词阶段全部丢弃。** 【压迫感审视】→"面部肌肉紧绷"，【胜券在握】→"双眼微眯、瞳孔聚焦"。标签是给导演看的批注，不是模型能渲染的指令，只有物理描述能进提示词。

## 校验清单（出片前逐条过）

1. **台词数一致性** —— 全局设定声明的"M 句台词"必须与实际台词条目数完全相符。数字不符会让模型漏掉一句
2. **时间码无缝隙连续** —— 镜1 结束于 2s，镜2 必须起始于 2s；各镜之和 = duration
3. **段总时长逐镜累加核对** —— 不能凭估算。实测踩过：把 2.0+3.0+1.5+2.0+5.0+3.0+3.0+4.0+2.5+2.5 报成 26.0s，实际 28.5s
4. **时长按台词长度校准** —— 拆镜时长是估算，长台词镜须放宽（台词字数每秒 3-5 字，见 SKILL.md §7）
5. **焦段序列相邻不重复** —— 逐段核对
6. **前景遮挡物过三检验** —— 几何 / 空间 / 必要性，见 `shot-language.md` §八
7. **道具状态连续性** —— 按道具时间线逐镜核对，见 `shot-language.md` §九
8. **VO 镜写明入画角色闭口** —— 逐条检查，不能只在收尾重申里写
9. **空间切换 vs 顺切** —— 同空间连续镜不得写硬切，见 SKILL.md §4
10. **资产层描述剥离** —— 逐条过【角色设定】【场景资产】【道具资产】【场景与空间说明】，删掉所有具体外观/服装颜色/家具材质/陈设元素描述，一律改成"严格以本图为唯一依据，不额外描述..."口径。**唯一例外**：剧情必需但参考图未包含的道具走"无参考图文字道具"通道，写明"无参考图，仅文字驱动"

## 分段提交规则

一集剧本超 30s 时按 ≤30s 切段。**每段是一次独立提交**，所以：

- @图片N 与 @音频N 编号**每段从 1 重新编**
- 镜号**每段从 1 重新编**
- 时间码**每段各自从 0s 起算**
- 段间靠叙事节拍边界切，不在一通电话的交错叙事中间切断

分段依据见 SKILL.md 多镜头纪律（30s 是天花板不是目标 / 叙事节拍边界 / 空间切换密度 / 收束重音镜放短段）。段间衔接手法见 SKILL.md「拆段生成的衔接手法」。

## 常见陷阱

- **资产层复述外观 = ref-vs-prompt 冲突漂移**（高频反复踩坑）—— 在【角色设定】写"红色礼服"、【场景资产】写"落地窗+城市天际线"、【场景与空间说明】写"宽大黑色皮椅/真皮办公椅"，一旦参考图不完全一致，模型会在文字与图之间摇摆，出现服装色漂、场景多出参考图没有的元素、家具材质错乱。**硬规则**：资产层一律写"严格以本图为唯一依据，不额外描述..."；家具/道具与图矛盾时**中性化**（"真皮办公椅"→"办公椅"，"玻璃办公桌"→"办公桌"）；参考图没有的环境元素（如会议室落地窗、办公室城市天际线）**直接删**；剧情必需但图里没有的道具（壁挂显示屏播疯传视频）**走"无参考图文字道具"通道保留**，别误删剧情道具
- **单图承载的代价** —— 每个人物一张图承载脸+发式+服装时，角色换服装或状态变化（如"-浑身血迹泥污"后缀 token）必须准备一张新的独立参考图，不能靠换服装图解决
- **屏幕/录像内的角色服装与本场不同** —— 提示词里**不点名角色 token**（写"一名女性抱着啼哭的婴儿"而非"克莱尔"），一致性交给独立的录像参考图承担；点名会让模型用本场服装渲染录像画面
- **服装与场景资产同色系** —— 如亚麻色衬衫贴米色沙发会糊进背景。在光影栏加"暖光在衬衫边缘勾出一道轮廓光把人物从同色系背景中分离"，更稳的做法是把场景资产换成深色
- **改服装时的连带改动** —— **只在真的换了参考图时触发**：查前景遮挡物（"白衬衫袖口"→"蓝色外套袖口"）、声音拟音（"开衫布料摩擦声"→"衬衫布料摩擦声"）、光影里的材质高光描述。**没换参考图不要动这些**——按新规则它们本就不该在提示词里出现
