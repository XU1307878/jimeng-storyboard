# 镜头语言 / 美学词典

> 用途：写六层结构时查这份词典——**美学前缀**查 §一~§六，**空间站位/动作表演**查 §七（纯视觉几何化）与 §十一（情绪微表情词库），**纵深层次**查 §八（前景遮挡三检验），**道具/状态连续性**查 §九，**快切块蓄势**查 §十。公式与控制口径以 [`wan3-formulas.md`](wan3-formulas.md) 为准，本文件只提供跨场景通用的美学、镜头语言、声音类目、几何化朝向、道具连续性与情绪物理描绘词汇，以及可直接套用的写作手法。

## 一、镜头语言 / 美学词典

直接把这些词塞进提示词前段即可生效，推荐写法是**「一串美学词 + 逗号 + 一段画面叙述」**。

| 维度 | 可用词 |
|---|---|
| 光源类型 | 日光、火光、阴天光、晴天光、实用光、混合光、荧光 |
| 光线类型 | 柔光、硬光、侧光、边缘光、背光、逆光、顶光 |
| 明暗/饱和 | 高对比度、低对比度、高饱和度、低饱和度 |
| 时间段 | 白天、夜晚、黎明、黄昏、日出、日落 |
| 景别 | 特写、近景、中近景、中景、中全景、全景、极端全景 |
| 构图 | 中心构图、对称构图、平衡构图、左侧重构图、右侧重构图、短边构图 |
| 镜头焦段 | 长焦镜头、中焦距、广角、超广角-鱼眼、移轴镜头。**焦段功能**：35mm 建立环境与地理关系；40mm 自然观察人物与空间（最适合单场景高概念）；50mm 克制反应、手部细节与结尾重释；85mm 肖像压缩与产品英雄镜；微距/长焦只在接触细节或远距离观察确有需要时用 |
| 机位角度 | 平拍、仰拍、俯视角度拍摄、低角度拍摄、高角度拍摄、过肩镜头角度拍摄、航拍、顶视镜头 |
| 镜头类型 | 干净的单人镜头、双人镜头、群像镜头、定场镜头 |
| 色调 | 暖色调、冷色调、混合色调 |
| 基础运镜 | 固定镜头、镜头推进、镜头拉远、镜头向左/右移动、镜头上摇/下摇、镜头跟随 |
| 高级运镜 | 环绕运镜、复合运镜、无人机镜头快速穿越、跟随视角 |
| 视觉风格 | 毛毡风格、3D卡通、像素风格、木偶动画、黏土风格、黑白动画、定格动画、赛博朋克、勾线插画、废土风格、纪实摄影风格、8-bit 像素风、VHS 故障美学、CRT 扫描线 |
| 特效镜头 | 移轴摄影、延时拍摄、剪影、丁达尔光效、浅景深虚化 |

**典型开头节奏**（可直接套用）：
> `边缘光，低对比度，中近景，日光，左侧重构图，干净的单人镜头，暖色调，柔光，晴天光，侧光，白天，` + 画面叙述…

## 二、声音类目清单

**音效写作清单**：
脚步声、敲门声、物体坠地、撞击声、火焰燃烧声、游戏音效（8-bit）、电子/故障声、ASMR、动物叫声、键盘声；
环境音分自然环境 / 城市环境 / 特定空间；
BGM 分情绪音乐 / 卡点音乐 / 轻音乐。

**人声类目**：单人说话、多人对话、音色指定、方言（如地道京腔）、唱歌。

**气口与无声留白**（精确控制音效时序）：
- **气口**：带秒数的呼吸节点——「倒抽一口凉气 0.8s」「沉稳的呼吸留白 1.0s」「屏息 1.5s 后缓缓呼出」
- **无声留白**：刻意静音的节拍——「无声留白 2.0s」「画面定格无声 0.5s 后音效渐入」
- 气口/留白写在动作之后、台词之前，控制「动作 → 气口 → 台词」的节奏链

## 三、光线动机纪律

光线必须有来源，不靠"电影感"三个字完成照明：

| 光源动机 | 写法 | 适用场景 |
|---|---|---|
| 窗光 | 「窗光从画面左侧斜射」 | 室内日景 |
| 实际灯 | 「桌灯暖光从下方照亮面部」 | 室内夜景 |
| 棚拍灯 | 「棚拍柔光从右上方 45 度投射」 | 影棚/广告 |
| 日光 | 「晴天日光直射，高对比」 | 户外日景 |
| 屏幕光 | 「屏幕冷蓝光映在脸上」 | 科技/夜间室内 |
| 反射光 | 「水面反射光波动画在脸上」 | 水边/雨后 |
| 火光 | 「篝火暖光跳动」 | 古装/野外/夜间 |

> 写清方向、衰减和反射。要求真实皮肤、柔和高光滚降、可读阴影。禁止无来源炫光、廉价 HDR、塑料皮肤、边缘光晕。

## 四、题材锺点风格表

常见题材的全局视觉风格映射，写美学前缀时可直接套用或就近类比调整：

| 题材 | 色温/色调 | 光照 | 质感 | 关键参数 |
|---|---|---|---|---|
| **写实年代剧**（农村/年代/家庭） | 3500K 暖灰，低饱和 LOG 观感 | 阴天柔光，低对比 | 胶片颗粒感，纪录片式克制 | 色板：水泥灰、土褐、暗青绿 |
| **民国/旧上海** | 双色温对撞：4300K 暖黄 + 6800K 青蓝 | 伦勃朗光 + 逆光轮廓 + 丁达尔 | 湿地反光、雨雾辉光，紧张但唯美 | 亮度/对比度/柔焦给具体数值 |
| **3D 漫剧/仙侠/国漫** | 高级灰低饱和 + 金/朱红/月白点缀 | 暖金冷青双色光 | 离线渲染壁纸级，次表面散射瓷白肌肤 | 通透水润瞳孔、多层轻纱+金线刺绣 |
| **现代都市情感** | 5000K 中性偏冷 | 城市玻璃幕墙冷暖光 | 数字电影机质感 | 主色板：灰蓝、银白、暗青 |
| **古装宫斗** | 暖黄 + 黛青 | 戏剧光（伦勃朗变体） | 实拍质感 | 主色板：宫墙红、铍金、黛青 |
| **悬疑刑侦** | 冷青主调，压低亮度 | 手持镜头呼吸感 | 加大暗部占比 | 主色板：冷灰、暗青、黑 |
| **2D 动画** | 参照 3D 锺点替换为手绘质感 | 赛璐珞/厚涂质感 | 线条、上色、纸张纹理 | 保持逐帧运动规律 |

> 新题材通过**就近类比 + 差异化调整**生成：找到上表中最接近的锺点，替换该题材特有的色板/光照/质感，保持框架结构不变。
> **参数必须具体量化**：色温写 K 值，虚化写百分比，禁止"适当""合理"等模糊词。色板必须列出具体颜色名，不写"低饱和色系"了事。

## 五、三个值得抄的手法

1. **声音与画面动作逐点对齐**：例如乒乓球弹跳写「每一次弹跳精确同步的有节奏的敲击声」「伴随着逐渐变弱的清脆撞击声」—— 音效跟着物理衰减写，比只写"有弹跳声"可控得多。
2. **台词直接内嵌在画面叙述里**：`…嘴部自然开合，用地道的京腔说道："哟，吃了么您呐？"` —— 口型描述 + 台词引号 + 口音，三件一起给。
3. **无人声要显式声明**：例如自然环境片写「没有对白或人声；环境音包括树叶轻柔的沙沙声…」—— wan3.0 默认有声，这条尤其重要。

## 六、转场方式术语

> **🚨 核心口径：按场景选多样转场，忌一律硬切。** 每到一个切点先判断「人物 / 场景 / 时间是否跳变」：都没变就用**运镜衔接（不切）或顺切**；有跳变就从下表按性质挑一个**符合该场景情绪与逻辑**的手法。**硬切只是其中一种**（叙事反转/爆点用），每镜开头都无脑写"硬切"= 严重错误。完整选择决策见 `prompt-craft-discipline.md` §10。

| 转场 | 写法 | 适用场景 | wan3.0 可控度 |
|---|---|---|---|
| 运镜衔接（不切） | 「镜头推进/拉远/跟随/环绕，不切镜」 | 同场景同时间连续动作 | ★★★ 最稳，主力衔接首选 |
| 硬切 Hard Cut | 「硬切」 | 跨主体/跨空间/跨时间的叙事跳；悬念反转爆点 | ★★★ 最可控，但别逐镜复制 |
| 淡入/淡出 | 「画面淡入」/「画面淡出至黑场」 | 段落起止；大时间跨度 | ★★★ 可控 |
| 遮挡 Wipe | 「镜头经过前景（柱子/门框/人影/衣袖）转场」 | 空间内转换；藏接缝 | ★★★ 可写，前景越大越稳 |
| 闪白 / 闪黑 | 「画面瞬间闪白」/「瞬间闪黑」 | 惊吓、闪回入口、猛拉回现实 | ★★ 可控 |
| 光效过渡 Light Shift | 「光线由冷蓝转为暖黄，key light 移动」 | 内在的时间/情绪推进；进入内景 | ★★ 一般，须明写光源路径 |
| 叠化 Dissolve | 「叠化」/「溶接」/「由前一镜缓慢叠化而来」 | 情绪温情过渡；回忆闪回 | ★★ 不稳，配 best-of-3 |
| 甩镜 Whip Pan | 「镜头快速横向甩动，甩至下一场」 | 动作连续但机位大跳；动感衔接 | ★★ 难控，慎用 |
| 匹配剪辑 Match Cut | 「动作匹配剪辑」/「形状匹配剪辑」 | 动作或形状衔接两场景 | ★ 难，配 best-of-3 |

> **判断口诀**：同场景连续动作→**运镜不切**（规避跨镜穿帮最稳）；同场景换机位→**顺切**（可不写词）；跨时空/情绪跳→按性质挑**叠化/淡入淡出/闪白闪黑/遮挡/光效过渡**等；只有叙事反转爆点才用**硬切**。让承接方式随剧情变化，而不是逐镜复制同一个词。
>
> wan3.0 是生成模型不是剪辑软件，转场靠「提示词描述 + 模型理解」实现，可控度低于真实剪辑。叠化/甩镜/匹配剪辑效果以实测为准，淡入淡出/遮挡/闪白闪黑相对稳。

## 七、纯视觉几何化词典（消除采访感与机械感）

**核心原则**：抽象社交词让模型自由发挥导致采访感与机械感；用几何语言锁定朝向、肢体、视线后，角色互动才能像真实电影场面调度。

### 禁用词表（严禁出现）

| 禁用词类 | 举例 | 为什么禁 |
|---|---|---|
| 抽象社交词 | 面对面、对峙、看着对方、交流、互相凝视、目光相交、面向彼此 | 模型理解为「两人朝镜头方向并排站立」，产生采访感 |
| 指示性转向词 | 转向对方、朝向他、看向她、望着你 | 「对方」无绝对坐标，模型随机分配朝向 |
| 抽象表情收尾 | 相视而笑、心照不宣、默默对视 | 无法可视化，模型生成随机表情 |

### 替换规则

**绝对朝向词**（面部/身体朝向）：朝向画面左侧 / 朝向画面右侧 / 背对镜头 / 侧脸约45度朝右

**肢体几何词**（四肢位置与重心）：双臂自然下垂、手指指向画面左方、身体微侧、重心后移、上半身前倾约15度

**视线落点词**（目光方向与高度）：视线水平投向画面右侧、目光落点在对方左肩高度、眼神斜向下方约30度

### 角度参考标准

| 角度 | 描述 | 用途 |
|---|---|---|
| 约30度 | 轻微侧转，接近正面 | 自然站立、弱互动 |
| 约45度 | 斜侧面 | 对话常用，既可见表情又不正对镜头 |
| 约90度 | 完全正侧面 | 侧面剪影、过肩镜头前景人物 |
| 约135度 | 偏背对，露出耳后轮廓 | 背景人物虚化、偷听/旁观 |
| 约180度 | 背对镜头 | 前景遮挡、过肩镜头背影 |

### 画面级否定 → 正面描述转换

| 画面级否定 | 正面描述 |
|---|---|
| 不要正面朝镜头 | 面部约45度朝向画面右侧，呈侧脸 |
| 不要跨坑位乱走 | 始终固定在左侧坑位，位置全程不变 |
| 不要张嘴说话 | 嘴唇闭合，无口型动作 |
| 不要出现文字/字幕 | 画面干净，无字幕叠加 |
| 不要看镜头 | 视线水平投向画面右侧，不投向镜头 |

## 八、前景遮挡物三检验

前景遮挡物（焦外虚化的前景）的作用是建立纵深层次、暗示空间、框住主体引导视线，是反 AI 扁平感的有效手段。但**它不是逐镜必填项**——机械套用会产生几何上不可能的画面。每个前景遮挡物必须过三个检验：

| 检验 | 问题 | 不合格的后果 |
|---|---|---|
| **几何检验** | 这个物体真的在镜头与主体之间吗？ | 主体手持、贴耳、佩戴的物体不可能同时是前景遮挡物——手机贴在角色耳边时，它在画面里但在头部位置，不在镜头与脸之间 |
| **空间检验** | 这个物体属于当前空间吗？ | 办公桌边缘不能出现在书房镜里；跨空间交错叙事时尤其容易串 |
| **必要性检验** | 这一镜真的需要前景遮挡吗？ | 大特写填满画面时前景遮挡只会吃掉画面、不起作用 |

**不该设前景遮挡物的场景**：
- **100mm 微距大特写**（眼部、面部、物件）填满画幅时——前景无处安放，改用主体自身的层次（睫毛与眼眶、瞳孔高光）+ 轮廓光分离背景
- 已经用**侧边暗角**建立纵深的镜头——暗角已经完成了前景遮挡的功能，再加一层是冗余
- 主体自身有强轮廓光已与背景分离时

**常见几何陷阱**（实测踩过的）：
1. **角色正在使用的设备当前景** —— 角色盯着电脑屏幕打字时，屏幕在他面前，不可能在镜头与他之间。改用同空间的其他物体（办公桌边缘、卷宗边缘、绿植叶片）
2. **角色手持/贴耳的手机当前景** —— 手机贴耳的镜头里，手机不能同时出现在前景。改用空间陈设（台灯支架、书架边缘、桌沿）
3. **同一段内前景遮挡物重复** —— 相邻或同段多次用同一物体（如两次"办公桌边缘"）会显得机械，换用同空间的不同陈设

**自检**：写完一镜后问一句"这个前景物体此刻在画面里的哪个位置？它真的挡在镜头和主体之间吗？"——答不上来就删掉前景遮挡，改成侧边暗角或不设前景。

## 九、道具与状态连续性检验

**核心区分：前景遮挡物是构图手段，道具在画面里是内容状态。两者不能混为一谈。** 取消某镜的前景遮挡，**不等于**把该道具从画面里删掉——角色此刻手里拿着什么、身上穿着什么，由故事时间线决定，不由这一镜的取景需要决定。

最容易踩的错：把"手机贴耳"当前景遮挡判定为几何不成立后，顺手把"手机贴在右耳"整句删掉。结果是角色在通话中却两手空空，道具状态断裂。

**逐镜四步检验**：
1. **此刻角色手里/身上有什么？** —— 按故事时间线查，不是按这一镜想拍什么查
2. **它在画面里可见吗？** —— 可见就**必须写进画面内容**（即使不承担前景遮挡功能）
3. **不可见时怎么办** —— 被景别排除（如眼部大特写填满画面，耳边的手机在画面外）可以不写，但**不能与之矛盾**（不能写"双手空着""手里没有东西"）
4. **道具状态的变化点必须显式** —— 拿起、放下、反扣、戴上等动作要单独成镜或明确写入，且变化前后的镜头要与之一致

**电话戏道具时间线示例**（一部电话贯穿多段时必查）：
```
维克多的手机：桌面免提 → 点按接听 → 全程留在桌面（他边打字边通话）
              → 某一镜拿起贴到左耳 → 此后每镜都在左耳
克莱尔的手机：贴在右耳 → 全程贴在右耳 → 末段放下反扣在桌面 → 此后不在手中
```
沿这条时间线逐镜核对，凡是"手机应该在画面里却没写"的镜头都要补。

**其他常见连续性断裂**：
- 免提通话时手机在桌面，但镜头只写角色打字、不写桌上亮着屏的手机 → 观众不知道通话还在继续
- 角色受伤后换服装（状态后缀 token），但后续镜头仍用旧 token → 服装被洗白
- 道具从 A 手换到 B 手、从桌上拿到手里，中间没有交代

**自检**：写完一镜后问一句"这一镜里，角色手里应该有什么？我写了吗？和上一镜一致吗？"

## 十、快切块设计规则与适用边界

快切块 = 连续 **2-4 个**约 1s 的无台词短镜，用来在张力峰值前蓄势、给短漫剧观众一个视觉刺激点。它是短漫剧提升观影体验的有效手法，但**有明确的适用边界，不能全片套用**。

### 适用边界（先判断，再设计）

| 段落性质 | 是否适合快切块 | 原因 |
|---|---|---|
| **张力累积段**（冲突 / 对抗 / 攻势 / 价值观交锋） | ✅ 适合 | 快切给即将到来的重音镜蓄势 |
| exposition 段（信息交代） | ❌ 不适合 | **信息峰值 ≠ 张力峰值**——若对方全程配合、没有阻力，双方在合作而非对抗，A/B 交替没有对抗内容可承载，加了是视觉噪音 |
| **情绪沉淀段**（脆弱 / 悲痛 / 哀悼 / 情绪转化） | ❌ 不适合 | 情绪需要呼吸空间，快切会打断转化过程（如"脆弱→杀意"这条链会被切碎）；且这类转化往往是纯内部的，没有 B 可交替 |
| 收束段 / 独角静态戏 | ❌ 不适合 | 收束重音需要余韵；独角戏没有对手，交替无从谈起 |

**落点判断**：快切块放在**张力峰值之前**，不是随机插入。找到该段最强的那一拍（底线声明、决断、反转），把快切块插在它前面。

**一段内最多一个快切块** —— 两个块会让这个技法从标点符号变成默认节奏（同"每镜都写硬切转场 = 机械复制"的毛病）。快切块的价值在于它是**例外**，例外出现两次就不是例外了。

### 子镜数量：不固定，按蓄势需要的信息量选

| 数量 | 结构 | 适用 |
|---|---|---|
| **2** | A / B | 单次交锋。小的对抗拍，或段落本身较短 |
| **3**（默认） | A / B / A | 完成一个回合，回到 A，有"回合结束"感 |
| **4** | A / B / A / B | 大的升级拍。但要警惕变成蒙太奇、失去标点感 |

硬约束只有两条：**每个子镜 ≥1.0s**（豁免常规 2s 下限，见 SKILL.md 多镜头纪律）；**块的总时长不超过段时长的 ~20%**，否则块会主导段落节奏。

设计时先问："蓄势需要几条信息？"——如果两个角色的状态信息有重叠（如两次都拍 A 的等待），就砍到 2 个。

### 八条设计规则

1. **落点在张力峰值之前** —— 为重音镜蓄势
2. **数量 2-4，按信息量选**，默认 3
3. **全部无台词** —— 快切块靠视觉节奏，不靠对白
4. **全部固定机位** —— 1s 内没有时间完成任何运镜
5. **必须交替两个角色** —— 来回本身就是张力装置；同一角色连续多个会失去对抗感
6. **信息类型递进** —— 动作 → 表情 → 物件反射（范例：手指停在键盘上方 / 双眼微眯瞳孔缩紧 / 镜片反射屏幕蓝光）
7. **光影写"与镜N一致"** —— 继承前镜光影描述，省 token
8. **衔接逐子镜写明下一目标**，并打叙事功能标签 `(快切)`

### 格式样板

```
【镜N】（快切）N连连续快切块+全部固定机位（起s-止s）

  子镜a（起s-止s）景别+固定机位+前景
  画面内容：…单一视觉事件加一个微动作。背景虚化，保持低存在感
  光影：与镜X一致，…
  声音设计：…
  台词：无
  风格锚点：…
  衔接：快切至…

  子镜b（…）…
  （子镜c、子镜d 按需）
```

### 不能加快切块的段落，用别的刺激装置

短漫剧每段都需要刺激点，但**不同性质的段落用不同装置**——不是"其他段缺刺激点"，而是它们该用适合各自性质的手法：

| 段落性质 | 刺激装置 |
|---|---|
| 张力累积段 | **快切块**（A/B 交替） |
| exposition 段 | **微动作重音**（手指轻点两下作重音、笔尖停顿）+ 长台词内的语速变化 |
| 情绪沉淀段 | **微表演**（眼眶微红 / 唇线颤 / 深呼吸 / 瞳孔收紧）+ **运镜性质变化标记转折**（如从"机械精准"转为"缓慢推近"标记角色的态度转变） |
| 收束段 | **空间转移 + 运镜推进 + 特殊构图**（斯坦尼康跟拍 → 缓慢推向玻璃 → 倒影双层影像 / 定格收尾） |

### 代价与回退方案

- **跨空间切换密度骤增**：交替意味着块内每多一个子镜就多一次跨空间切换，漂移风险上升。这是张力来源的固有代价；**减到 2 个子镜可把块内切换从 2 次降到 1 次**
- **回退方案**：若实测发现串空间，把全部子镜放在同一空间一侧（如只拍 A 的手 / 唇线 / 瞳孔），代价是失去对抗感
- **子镜内容要核对角色资产**：如"镜片反射"需要角色确实戴眼镜，剧本没写就不能用——改用同空间的其他视觉（下颌收紧 + 屏幕光在脸上移动）
- **时长核算**：快切块整体计入段时长，段总时长仍须 ≤30s

## 十一、情绪微表情与肢体强制词库（近景及以上特写）

> **用途边界（最重要）**：本表用于把**原文已给的情绪基调 / 情绪名**翻译成物理描绘，**不是用来发明情绪**。原文未给情绪方向时（只说"表情丰富些""情绪要有变化"），遵守 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §13.2「什么都没给 → 只写中性表述、不设起止/趋势/强度、不从情节反推方向」，**禁止从本表挑一条强加到角色脸上**。
> **取用规则**：① 每镜只抓 **1 条**最贴合的，可拆用其中 2–3 个生理动作，**不要把整表或整条堆进 prompt**；② 条内含"对方 / 对视 / 越过对方"等社交抽象词的视线句，取用后仍须过 **§七 几何化替换**（改成绝对朝向或落点，如"视线水平投向画面右侧""目光落点在对方左肩高度"→ 具体坐标）；③ **仅近景及以上特写**才写瞳孔 / 睫毛 / 嘴角这类面部微表情，**中景 / 全景**面部不可见，改以肢体姿态与重心为主，硬写瞳孔反而不生效。
> **与既有规则一致**：本表条目本身已是"从 A 到 B 的变化过程"（如"眉心轻拧又松开""嘴角不自觉上扬又立刻压下"），直接对应 §2「情绪写变化过程而非静态形容词」，取用时无需再改写为过程式。
