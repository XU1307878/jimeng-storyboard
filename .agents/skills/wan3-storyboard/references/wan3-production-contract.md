# Wan 3.0 生产契约

## 一、实际素材门

复制即用的提示词必须先列素材状态：

| 状态 | 是否允许写@引用 | 处理方式 |
|---|---:|---|
| 用户已上传且编号明确 | 是 | 写明唯一主要职责 |
| 用户说稍后提供 | 否 | 标记“待上传”，不得伪装成已绑定 |
| 只有文字描述 | 否 | 使用角色名或场景事实继续草案 |
| 文件缺失或路径不可读 | 否 | 说明无法验证，不拿其他文件替代 |

提示词里出现 `@ImageN/@VideoN/@AudioN` 不等于素材真实存在。若没有实际上传，对应身份、场景、动作或声音只能视为未锁定变量；生成结果不得判为“模型忽略参考图”。

## 二、素材职责

- 人物身份图：只锁脸、年龄、发型结构、体型和已确认服装，不照搬设定页排版、白底或多视图重复人物。
- 场景图：锁建筑结构、门窗、固定家具、入口出口和物理光源；人物站位只有在用户明确选择参考图锁定时才继承。
- 道具图：锁同一件道具的外观、尺寸、材质和关键标识，不额外生成第二件。
- 首帧图：锁第0秒的构图、位置、朝向、接触和光线，不自动承担整段动作参考。
- 音频：写明说话人和对应台词窗口；未上传音频时不要保留假的 `@AudioN`。

每个素材编号必须在映射和正文中对应同一对象，禁止同一编号同时代表人物、场景和道具。

## 三、提示词骨架

```text
【参考素材职责】
@Image1：__；主要控制__；不继承__

【视频规格】
时长、画幅、媒介、时间地点、允许出镜人物

【剧情目的】
本段唯一变化或信息增量

【空间与光线锚点】
场景结构、轴线、视线、物理光源、方向、软硬、色温、曝光优先对象、背景关系

【时间轴与镜头】
0—__秒：景别/机位；触发；动作路径；表情和微表情；对白窗口；镜尾状态

【声音】
对白、环境、动作反馈、静默点；无需要时不强加BGM

【连续性限制】
只写本镜最可能失败的身份、空间、道具、口型、光线和镜尾风险

【验收点】
下一版必须出现的可观察结果
```

## 四、光线锚点

先写可见光源，再写效果：

`光源实体 → 所在方向和高度 → 入射方向 → 软硬与色温 → 主要照亮对象 → 背景明暗关系 → 跨反打不变量`

- “电影感、氛围感、高级光影”不能代替物理光源。
- 正反打只改变摄影机，不能让窗户方向、鼻影方向和背景亮区无因反转。
- 曝光优先服务当前信息：眼神、手部动作或关键道具。纸张要可读时不得高光过曝。
- 同一生成片段只保留一套主光逻辑；光线变化必须由开灯、关灯、移动、遮挡或时间变化触发。

## 五、关键文字道具

独立道具参考可以提高版式和结构一致性，但运动生成仍可能重绘汉字。正式制作时按重要性选择：

1. 普通参考：文字不承担剧情时使用。
2. 首帧锁定：文字必须在开头短暂停留且当前界面支持首帧时使用。
3. 单独静态插入或后期UI：逐字准确是剧情硬要求时优先。

不得因为上传了文字道具图，就承诺模型一定逐字保真。审片时分别检查版式继承和文字准确性。

## 六、时间轴与表演

- 对白开始和结束必须落在明确时间窗内，镜尾至少留出可见反应或稳定结束状态。
- 不给手部特写安排看不见的眼神、眉毛或下颌表演。
- 服装必须支持动作；短袖角色不能“把手缩进袖口”。
- 一段对白的听者反应按触发顺序发生：动作停止、呼吸变化、视线移动、抬头或开口，避免第一秒演出最终情绪。
- 背景人物只有剧情或场景资产允许时才出现；未上传场景参考时，模型自行补全的空间只能作为无参考基准样片。

## 七、审片与最小修复

先区分失败来源：

- 没有真实参考素材：输入缺失，不判定模型忽略参考。
- 有参考但职责不清：素材映射失败，先修职责。
- 有明确参考仍偏离：模型执行失败，冻结其他成功层后重跑。
- 逐字文字漂移：优先改用首帧、静态插入或后期，不无限堆叠提示词。

每次修复只设一个主要变量，并写清必须冻结的身份、空间、动作、表演、光线、声音和镜尾成功项。
