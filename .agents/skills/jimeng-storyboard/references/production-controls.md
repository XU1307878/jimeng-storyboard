# JiMeng production controls

## 1. 素材角色映射

给每个上传素材分配一个主角色，避免模型把“参考”误解成“复刻”。

| 编码 | 作用 | 提示词写法 | 使用边界 |
|---|---|---|---|
| `R-DESIGN` | 设计参考，仓库默认 | `人物设计参考@图片1（姜禾），仅参考脸型、发型、服装和配色` | 不作首帧，不复制二维画风和构图 |
| `R-IDENTITY` | 强身份锁定 | `人物身份与五官参考@图片1（姜禾）` | 仅在用户明确要求锁脸时使用 |
| `R-FIRST` | 首帧 | `@图片1作为首帧` | 起始构图必须与图片一致 |
| `R-SCENE` | 场景空间参考 | `场景结构参考@图片2（出租屋）` | 可重新设计机位，不照抄原构图 |
| `R-MOTION` | 运镜/动作参考 | `运镜轨迹参考@视频1` | 只学运动，不复刻人物和场景 |
| `R-AUDIO` | 节奏/声音参考 | `声音节奏参考@音频1` | 标明参考音乐、音色或节拍中的哪一项 |

规则：

- 使用即梦编号：`@图片1`、`@视频1`、`@音频1`。
- 每个引用后立刻写清主体名和用途，禁止裸写 `参考@图片1`。
- 相邻镜头固定同一编号。图片、视频和音频合计不超过12个。
- 用户只说“参考图”时，一律使用 `R-DESIGN`。
- 参考图若为二维设定页，明确写“不复刻多视图排版、边框、标签和画风”。

## 2. 镜头编码

使用 `Z/Y/X/F` 规划，输出时同时给出编码和自然语言。

### Z：景别与距离

- `Z1–Z2`：大特写/局部特写，用于手机、眼睛、手、线索。
- `Z3`：面部近景，用于单一反应和情绪落点。
- `Z4–Z5`：中近景/中景，用于对白和手部动作，默认选择。
- `Z6–Z7`：四分之三身/全景，用于走位与完整动作。
- `Z8–Z9`：远景/大远景，用于建立空间和世界观。

### Y：相机高度

- `Y6`俯视、`Y5`轻俯、`Y4`平视、`Y3`轻仰、`Y2`仰视。
- 默认 `Y4`。只在叙事需要弱化、压迫或崇高感时改变高度。

### X：相机方位

- `X1`正面、`X2`四分之三侧、`X3`侧面、`X4`背面。
- 默认 `X2`，最利于3D面部和体积稳定。

### F：焦段与光学

- 24mm：环境、室内全景；35mm：日常叙事；50mm：对白；85mm：克制特写；微距：手机和道具。
- 只写一个焦段。景深、拉焦或变形宽银幕是光学补充，不是第二个运镜。

## 3. 运镜冲突检查

- 每镜只有一个主运镜；环境微动不算第二运镜。
- 同镜禁止同时推近和拉远，除非明确使用希区柯克变焦。
- 同镜禁止同时写“缓慢”和“快速”。
- `Z1–Z3`近距离避免大角度环绕；改用 `Z4+` 或小于15度的轻微侧移。
- 参考视频方向与文本方向冲突时，以用户明确指定的方向为准并重写另一项。
- 不要把推进、环绕、升降三轴塞进一个短镜头。
- 固定机位也要写清主体和环境中什么在动，防止生成静帧。

## 4. 3D品质四层控制

只选择镜头需要的细节，避免关键词堆砌。

1. **形体层**：国漫半写实比例、真实中国人面部结构、稳定面部绑定、正确手部和重心。
2. **材质层**：PBR皮肤与克制SSS、发丝、织物编织、磨损木石金属、湿表面反射。
3. **光照层**：全局光照、物理衰减、实景光源、轮廓光、体积雾和自然景深。
4. **运动层**：自然眨眼、呼吸、口型、发丝和衣料次级运动、真实物体接触。

山海场景的水墨只进入材质、雾、色彩与构图，不改变角色的三维结构。

## 5. 开头两秒钩子

当用户要求片头、开场或短剧钩子时，前两秒必须出现一个可见的信息点：

- 异常界面亮起；
- 不可能的声音与角色反应；
- 危险动作已经开始；
- 一句能改变关系的问题；
- 角色正在掩饰的情感伤口。

钩子必须来自剧本。不要为了刺激而添加新人物、新灾难或新台词。

## 6. 连续性接力棒

为每镜记录 `入镜状态` 和 `出镜状态`：

- 角色位置与朝向；
- 手中物和接触关系；
- 镜头的运动方向；
- 光线、天气和环境声；
- 结尾可持续的动作或定格。

下一镜优先继承上一镜的出镜状态。跨世界切换则在黑场、遮挡、水花、手机光或声音尾巴中完成。

## 7. 空间与轴线编码

- 多人场景先确定空间状态：`参考图锁定 / 文字俯视图锁定 / 不锁定 / 待确认`。没有用户确认时，不得把导演猜测的左右站位写进最终生成提示词。
- 采用文字俯视图时，先检查背景到摄影机的景深链，再检查固定桌椅没有出现在错误的人物层级。
- 场次使用稳定ID：`SC01`、`SC02`。
- 每条主轴线使用稳定ID：`AX-A`、`AX-B`。只有重新建立空间后才能更换。
- 用 `L/C/R` 表示画面左/中/右，用 `N/M/F` 表示近/中/远景深层。
- 每镜写清人物位置、朝向、目线、关键道具和运动方向。
- 正反打不得无解释越轴。需要越轴时使用可见越轴、中性正面或新的建立镜头。
- 复杂场次优先输出纯文本俯视图供用户确认；只有用户明确要求时才生成图形化空间图。

推荐格式：

> 场景锁定：SC01 / AX-A / 状态=已确认；人物=姜禾L1面向右，鹿九R3面向左；目线=姜禾→鹿九；道具=手机在姜禾右手；运动=姜禾左→右。

## 8. 微表演控制

从以下维度选择二至四项，不要全部堆入一镜：

1. 目线：目标、停留、躲闪和回看。
2. 眼睑与眉间：眨眼频率、收紧或轻压。
3. 嘴与下颌：笑意停住、嘴角回落、绷紧或吞咽。
4. 呼吸：短吸气、屏息、吐气和胸口起伏。
5. 手部压力：指尖、抓握、松开和接触反馈。
6. 肩颈与姿态：肩膀、颈部、背部和防御姿势。
7. 重心：前脚、后脚、停步或转身准备。

有背景人物时，分别写 `主体=` 与 `背景=`。背景反应幅度必须低于主体。

## 9. 当前镜头最小引用

- 项目级资产表可以完整，但每镜只带当前画面可见且有控制作用的参考。
- `素材映射` 与 `画面提示词` 中的@编号集合必须完全一致。
- 默认一镜不超过4个参考；超过时先考虑拆镜或删除弱参考。
- 同一资产在相邻镜头保持同一@编号，不因最小引用而重新编号。

## 10. 模型错误预判

每镜使用：

> 模型风险：风险=一至三个高概率错误；预防=对应的正向物理、空间或焦点约束。

优先预判：身份漂移、轴线反转、目线错位、人物瞬移、道具换手、手部接触错误、背景抢焦、风格串场、运镜冲突和模型文字。

## 11. 提示词预算

- 区分“生产文档总长度”和“送入模型的视觉载荷”。制作摘要、素材映射、台词、声音和检查项可以保留在文档中，但不要重复塞进视觉载荷。
- 每条视觉载荷优先压缩到约500个中文字符；约600字符作为软诊断线，超过时必须检查是否存在重复、文学化解释或无效画质词。不同平台的实际上限可能不同，不把该数字当成模型硬限制。
- 若完整交代身份、主体动作、镜头观察、时间节点、镜尾和关键连续性后仍超过软诊断线，优先拆片，不可为了追求短而删除核心控制。
- 精简顺序：重复形容词 → 重复画质词 → 次要背景细节 → 非关键负面项。
- 默认删除或降级装饰性参数词，如“8K”“IMAX”“阿莱摄影机”“电影级画质”；只有当它们对应用户明确要求且能转译成可见结果时，才保留具体可见结果。
- 不得删掉：当前镜头参考及其作用、主体、主要动作、镜头如何观察、必要时间节点、光线来源、结束状态和关键连续性。
- 不用关键词复读或未经证实的数值权重语法增强权重。靠顺序、明确主语、角色绑定、时间范围和减少竞争信息建立语义优先级。
- 精确中文、UI和字幕全部移至 `后期叠字`。

## 12. 输出前检查

- 每个素材均有角色编码和用途。
- 所有角色参考图没有被误写成首帧或目标画风。
- 每镜不超过15秒，时间线无空档和重叠。
- 每镜只有一个主动作和一个主运镜。
- 3D角色、材质、光照和动作至少各有一个有效约束。
- 入镜状态承接上一镜出镜状态。
- 高风险场次已写场景ID、轴线ID、左右位置、目线或运动方向。
- 每镜包含可观察的微表演，不只写抽象情绪。
- 每条可复制提示词均可独立执行，未依赖“同上/延续上一镜”作为唯一连续性信息。
- 首帧已有明确主体、左右与景深位置、朝向/目线、接触状态和有来源的主光。
- 素材映射与提示词中的@编号集合一致。
- 每镜已写模型风险与正向预防。
- 每镜明确新增了动作、情绪、信息或声音变化，未重复讲述上一镜。
- 每镜具有进入、发展和可继承的离开点，镜尾能触发下一镜。
- 声音至少包含环境底噪与动作反馈；人物声和画外声按剧情使用，且至少一个声音属性随镜头发生合理变化。
- 台词、声音和后期文字与画面提示词分离。
- 每条视觉载荷已检查约600字符软诊断线；超过时已说明必要性或完成拆片。
