# 影视布光语法

本文件吸收Xuan酱《AI视频想要电影感？用好这6大影视级布光技巧》的课程框架，并将其转译成分镜决策。课程示例是创作参考，不是固定模板；不要因为某种灯光“像电影”就把它机械套到所有镜头。

## 1. 布光先回答剧情

每镜先回答四个问题：

1. 观众此刻必须看清什么？
2. 人物是被揭示、被隐藏、被压迫、被分割，还是与背景分离？
3. 场景中什么真实或可信的光源能完成这个任务？
4. 上一镜的光从哪里来，下一镜必须继承哪些不变量？

“电影感”不等于画面更暗。若眼神、关键动作或道具因此不可读，布光就没有完成叙事任务。

## 2. 可执行光线句

使用以下顺序：

> `光源动机 + 屏幕方向与高度 + 软硬/面积 + 色温 + 主体受光结果 + 阴影与背景关系 + 连续性`

示例：

> 画左上方的旧吊灯作为唯一主光，偏硬暖光斜落在Lucian左侧额头与颧骨，眼窝保持阴影但瞳孔仍有微弱眼神光；右侧脸沉入冷灰环境阴影，肩线与石殿背景分开；灯位、色温和阴影方向承接上一镜不变。

不要只写“电影级顶光”“高级伦勃朗光”或“氛围感逆光”。

## 3. 方向型布光

### 顶光

光从主体上方落下，眉骨、眼窝和下颌形成垂直阴影。

- 适合：权力压迫、审讯、危险、孤立、隐藏眼神。
- 动机：吊灯、天井、顶窗、舞台灯、地下空间单灯。
- 必须控制：眼睛是否需要看清、鼻影长度、头部动作是否造成脸部忽明忽暗。
- 常见失败：整张脸变黑、熊猫眼、头稍微移动就闪烁。
- 正向写法：`眼窝压暗但瞳孔保留微弱反光；灯位固定，人物抬头时亮区连续下移，不发生曝光跳变`。

### 侧光

主光从画左或画右横向/斜向照亮一侧面部，另一侧进入阴影。

- 适合：内外冲突、立场分裂、警觉、决断、悬疑。
- 动机：侧窗、门缝、走廊灯、壁灯、火堆。
- 必须控制：明确屏幕侧和脸部角度；正反打时光源留在空间中的同一侧。
- 常见失败：反打镜头左右光互换，像灯跟着摄影机移动。
- 正向写法：`侧窗始终位于场景东侧；人物转头时受光面随头部旋转变化，但窗光方向不变`。

### 逆光

主光位于主体后方朝向摄影机，使轮廓、头发、肩线或烟雾被勾亮。

- 适合：人物登场、身份隐藏、孤独、告别、神秘、从背景中分离。
- 动机：门口、窗户、夕阳、车灯、火焰、舞台灯。
- 必须控制：主体脸部是否要读到；需要时加入极弱环境填充，而不是无条件做纯黑剪影。
- 常见失败：脸完全丢失、轮廓光溢出、发丝发光、背景过曝。
- 正向写法：`门外冷光只勾亮肩线和发丝边缘，脸部由室内极弱暖反射维持可读，门外高光不过曝`。

### 伦勃朗光

主光从人物前侧约45度并高于眼睛落下，阴影侧脸颊保留一个受控的三角亮区。

- 适合：秘密、矛盾、道德复杂、克制肖像、危险亲密关系。
- 最适合：近景或中近景、人物停留相对稳定的时刻。
- 不适合：快速打斗、多人频繁走位、三角亮区根本不可见的远景。
- 必须控制：脸朝向、灯位高度、阴影侧三角亮区和眼神光。
- 常见失败：亮三角漂移到错误脸侧、变成普通侧光、眼窝死黑。
- 正向写法：`画左前上方硬度适中的主光在右侧脸颊留下稳定小三角亮区，两眼均保留克制眼神光`。

## 4. 质感型布光

方向和质感是两个维度。侧光可以是柔光或硬光，逆光也可以通过雾形成体积光。不要把它们当成互斥标签。

### 柔光

大面积或经过漫反射的光包裹主体，阴影边缘缓慢过渡。

- 适合：日常、亲密、脆弱、疗愈、自然人像。
- 动机：阴天窗光、纱帘、反射墙面、大面积天光。
- 常见失败：脸部过平、皮肤塑料化、人物与背景粘在一起。
- 修正：保留轻微侧向、负补光或背景明暗差，不靠磨皮表达柔和。

### 硬光

较小或直接的光源形成清晰阴影边缘和强明暗切割。

- 适合：威胁、暴力、审讯、正午、黑色电影、动作高潮。
- 动机：裸灯、直射太阳、探照灯、车灯、火焰直射。
- 常见失败：面部结构破碎、阴影随帧乱跳、皮肤质感过脏。
- 修正：固定光源和人物运动路径，写清阴影边缘落点与移动规律。

### 体积光

光束被雾、烟、尘、水汽等介质显形，用来交代空间深度和光源方向。

- 适合：门窗启示、神圣/超自然登场、废墟、舞台、烟尘环境、空间揭示。
- 前提：场景中必须有可信介质；无雾无尘时不要强行写“丁达尔光”。
- 常见失败：到处都是光柱、雾吞掉人物、光束方向漂移、密度闪烁。
- 正向写法：`稀薄尘雾只在窗光路径中显形，光束从画右上稳定斜向画左下，人物移动时遮挡关系变化但光束方向和密度不变`。

## 5. 光影连续性

同一场景建立一条光线母版：

- 主光物理来源与空间位置。
- 屏幕方向和高度。
- 软硬程度与衰减。
- 色温与环境补光颜色。
- 人脸最低可读亮度。
- 背景明暗层次和轮廓分离方式。
- 雾、尘、烟的密度和光束方向。

正反打、推拉或景别变化时，摄影机可以移动，光源不能无原因跟着摄影机移动。允许的变化只有：人物相对光源移动、遮挡物经过、火焰/屏幕等光源自身波动、门窗开合、灯具开关或剧本明确的世界变化。

每个允许变化都写成：

> `发生时间 + 物理原因 + 哪个区域先变 + 变化后的稳定状态`

例如：

> 第3秒门被推开，画右走廊冷光先切入地面，再爬上人物右侧肩线；室内暖主光保持不变，结尾形成冷暖双光但曝光不跳变。

## 6. 按剧情而非名词选择

| 剧情任务 | 优先方案 | 避免 |
|---|---|---|
| 隐藏人物意图但保留反应 | 克制顶光或伦勃朗光 | 眼睛完全不可读 |
| 表现立场撕裂 | 有动机的侧光 | 正反打光源换边 |
| 人物登场或从背景中显现 | 逆光加最低限度面部填充 | 轮廓溢光、背景过曝 |
| 亲密、脆弱、日常 | 有方向的柔光 | 无层次平光、磨皮 |
| 威胁、伤害、审讯 | 稳定硬光或顶光 | 阴影逐帧乱跳 |
| 展示空间、尘雾或超自然入口 | 有来源的体积光 | 无介质的装饰光柱 |

## 7. 输出前检查

- 已写光源是什么，不只写灯光术语。
- 已写光从画面哪一侧、什么高度进入。
- 已写柔硬、色温和主体可见结果。
- 眼神、关键动作和道具仍然可读。
- 正反打或相邻镜头没有无原因换边、变色、变亮。
- 体积光确有介质、方向和密度。
- 灯光服务本镜剧情，没有为“电影感”强行压暗或堆光效。
