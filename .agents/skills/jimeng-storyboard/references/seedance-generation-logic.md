# Seedance 2.0 生成逻辑与提示词取舍

本文件吸收《Seedance 2.0 模型使用认知误区与生成逻辑梳理》的生产经验，用于改进提示词决策。课程中的“约500字最佳区间”“约80%命中率”等数字属于作者经验和诊断指标，不作为官方硬限制或稳定保证。

## 1. 把模型当成自主生成器

Seedance 会根据画面、运动和叙事模式自主补足镜头。提示词不是逐帧程序，也不能保证所有描述等权执行。生产控制的目标是减少模型必须替导演决定的变量。

- 人负责节奏、镜头任务、关键节点和连续性。
- 模型负责在明确边界内生成运动与画面细节。
- 结果跑偏时先检查输入竞争、镜头负载和参考角色，不先归因于“算力下降”。

## 2. 视觉载荷预算

生产文档可以详细，但真正送入模型的视觉载荷要紧凑。

- 目标：在不丢失关键控制的前提下，尽量靠近500个中文字符。
- 诊断：约600字符以上，逐项检查重复、解释性文字、无效画质词和过多负面词。
- 处理：若仍需大量动作、转折或机位变化，拆成更短的生成片段或更少的内部镜头。
- 不得为了压字数删除身份/参考作用、主体动作、镜头观察、时间节点、镜尾状态或关键连续性。

字符预算只计算可复制的视觉生成正文，不计算生产文档中的标题、素材映射、台词、声音、后期叠字和检查说明。

## 3. 语义优先级

不使用未经证实的数值权重写法，也不靠重复关键词“加权”。按下面顺序组织竞争信息：

1. 当前镜头引用素材及其唯一作用。
2. 起始摄影机锚点：机位、高度、景别、朝向和必要的焦段。
3. 主体起始状态，以及在当前镜头坐标中可见的动作路径。
4. 由人物动作、视线或信息变化触发的唯一主运镜。
5. 关键时间节点及动作变化。
6. 镜尾可见状态和下一镜继承点。
7. 只与本镜有关的光线、色彩、材质或风格结果。
8. 一至三个高风险问题的正向约束与简短排除。

这种排序称为“镜头观察锚点前置”：在人物启动前先让当前生成片段拥有清楚的观察坐标，使动作与运镜共享同一空间关系。它不表示模型会像程序一样严格逐句运行，也不意味着镜头词可以压过素材身份、人物站位或剧情动作。

把抽象情绪转成动作、表情和微表情。把文学性因果留在导演分析中，不直接塞进模型载荷。

## 4. 主体 + 动作 + 镜头观察

最小有效句必须回答：

> 谁，在什么可见位置，以什么动作改变了画面；摄影机如何看见这个变化；镜尾停在什么状态。

不写“她陷入巨大的悲伤”。写“她松开门把，肩膀下沉，笑意停住，视线避开画右的人；固定近景停在她指尖离开门把的瞬间”。

复杂动线先在已确认场景中确定 `真实起点 → 地标路径 → 真实终点`，再根据当前摄影机的位置和朝向换算成画内方向。画左、画右、靠近镜头或远离镜头只控制本镜观察结果，不得改变参考图或俯视图锁定的真实位置。换机位后重新换算屏幕方向，但真实终点和关系轴线保持不变。

三层表演仍然保留：

- 动作：身体行为、接触关系和结果。
- 表情：观众直接读到的主要情绪或社会性伪装。
- 微表情：二至四个决定性信号，不堆满全脸细节。

## 5. 故事版干预

当模型未获得明确开场时，可能自主选择较宽的站位/建立画面，再从该基准延展。不要把这种倾向当成每次必然发生的规则。

- 需要精确开场时，明确写首个时间段的景别、机位、主体位置、朝向和接触状态。
- 多镜头片段用 `时间范围 + 景别/视点 + 主体 + 动作 + 镜尾触发` 编写。
- 每段只保留一条清楚的动作因果链；时间段无空档、无重叠。
- 0.5秒级特写只用于可一眼识别的插入信息，不承载复杂表演或长台词。
- 故事版或首帧提高关键节点确定性，但不等于全程逐帧锁死。

## 6. 参考素材的认知边界

参考图能帮助模型识别可见属性，却不能单凭一张图理解原创世界规则。

- 专属名词第一次出现时，改写为可见的形状、材质、颜色、运动和因果结果。
- `环境之书`之类名称不能单独承担控制；应写成“悬浮的厚重黑皮书，金属包角，翻页时纸缝溢出蓝光”等可见属性。
- 每个@素材只分配一个主角色：身份、设计、首帧、场景、动作、声音或风格。
- 垫图不是万能锁定。它不能自动补齐画外空间、角色关系、物理规律或原创设定逻辑。

## 7. 删除无效信息

优先删除：

1. 重复出现的风格和画质形容词。
2. 不能转化为可见结果的设备名或规格词，如“8K”“IMAX”“阿莱摄影机”。
3. 对主体动作没有影响的次要背景陈设。
4. 大段文学性解释、角色内心独白和剧情评价。
5. 与本镜无关的通用负面词。

需要“电影感”时改写成具体结果，例如低机位缓推、单侧硬光、背景压暗、浅景深或克制手持，而不是重复“电影级”。

## 8. 失败诊断与重试

一次只改变一个主要变量，避免无法判断哪项修改有效。先冻结身份、空间、动作、表演、摄影机、光线和声音中已经正确的层，再修失败层；不要整段重写导致已成功部分回退。

| 失败表现 | 优先检查 | 首选修正 |
|---|---|---|
| 动作遗漏 | 主体不明、动作过多、载荷过长 | 前置主语与主动作，删除装饰词或拆片 |
| 开场变成全景 | 未指定首镜或首帧 | 前置首段景别、位置、朝向和接触状态 |
| 角色/道具串用 | @素材没有唯一角色 | 重写素材映射，并在动作句中再次绑定主体 |
| 镜头时长失衡 | 时间段模糊、一个镜头承载多个任务 | 写连续时间范围，每段只保留一个任务 |
| 原创设定失真 | 只写专属名词 | 改写成可见属性、运动和结果 |
| “质感很好但剧情没发生” | 画质词抢占动作信息 | 删除设备/规格词，把主体+动作前置 |

重试前记录最小补丁：`必须保留的成功项 → 失败类型 → 可见错误证据 → 本轮唯一改动 → 新的可观察验收点`。若错误来自单片段承担过多说话人、动作、转折或运镜，选择拆片，而不是继续加长提示词。

## 9. 输出前快速检查

- 视觉载荷的第一屏已经出现当前参考、主体和主动作。
- 每个时间段都有明确景别或观察方式、动作和镜尾。
- 专属名词均有可见翻译。
- 装饰性画质词没有替代具体光线、镜头或材质结果。
- 超过约600字符时，已完成去重，或选择拆片而非硬塞。
- 所有数字阈值仅作诊断，不被表述成官方保证。
