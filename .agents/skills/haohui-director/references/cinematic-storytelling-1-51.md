# 电影化叙事选择库（1—51）

本参考把《电影化叙事》公开可读部分的前 51 种手法转译为短剧导演决策。它用于选择表达机制，不复制书中案例，也不要求每场戏堆叠技巧。

## 总原则

先写清当前节拍的戏剧任务，再选择手法：

`戏剧任务 → 观众需要感知的变化 → 可见/可听证据 → 最小有效手法 → 镜尾状态`

手法必须至少完成一项：改变信息、权力、情绪、空间理解、时间理解或因果预期。仅增加“电影感”而不改变观众理解的手法应删除。

同一节拍优先一个主手法，必要时加一个辅助层。空间、构图、表演、声音和剪辑不得互相表达相反意图，除非这种矛盾本身就是戏剧设计。

## 一、空间方向：1—6

可用 X、Y、XY、Z 轴把抽象关系变成运动关系：

- `X轴水平运动`：建立趋近、背离、对抗或会合。方向意义来自项目既有编码和当前场景，不机械套用“左正右反”。
- `Y轴垂直运动`：上升常可表现努力、脱离或权力提升；下降可表现失控、坠落或不可逆趋势。必须有真实地形或动作支持。
- `XY对角线`：比水平或垂直更不稳定，适合危险逼近、局势倾斜和艰难攀升。
- `Z轴景深`：人物向前景或后景移动时，用体量变化呈现权力、亲密、孤立或心理退缩。
- `Z轴动作平面`：把前、中、后景分配给不同人物、时间感或心理状态，让同一画面同时叙事。
- `Z轴移焦`：焦点转移必须等于信息或权力转移；明确起焦对象、触发点、落焦对象和落焦后的新含义。

执行前先锁真实场景坐标和关系轴，再换算为当前机位中的屏幕方向。不能为了象征意义改写参考图中的人物位置、家具或出入口。

## 二、构图：7—11

- `引导视线`：用亮度、色彩、清晰度、运动、尺寸或视线，把观众先带到决定性信息；不要让背景高反差物抢戏。
- `不平衡`：用偏置、空缺、压边或视觉重量失衡表现关系断裂、缺席、危险和心理失稳。
- `平衡`：用对称、对应或稳定重量表现秩序、联盟、依赖；一旦关系改变，可让平衡被动作打破。
- `方向异常`：倒置、倾斜或失向只在人物世界观确实失稳时使用，并给观众一个可理解的恢复点。
- `大小关系`：人物或物体的画面占比表达当前权力与重要性。变化要由走位、景别或镜头关系产生，而非无理由跳变。

构图的价值在“变化”。若开头与结尾构图状态相同，检查该镜头是否真的推进了戏。

## 三、画面形状：12—16

- `圆形`：可表达循环、封闭、包围、共生或宿命。
- `线形`：可表达路径、边界、秩序、选择或无法越过的阻隔。
- `三角形`：适合三人权力、争夺、联盟与主次稳定；顶点角色通常承担当前焦点。
- `矩形/框中框`：适合禁锢、隔离、制度压力、窥视和被审视。
- `有机形与几何形对比`：可区分自然/制度、自由/控制、亲密/疏离，但意义必须由本剧世界建立，不把符号当固定答案。

形状首先来自场地、家具、走位和群像关系，不能凭空生成破坏空间逻辑的物件。重复形状要在后续发生意义变化，才形成视觉母题。

## 四、剪辑：17—25

把剪辑看成意义生成，而非单纯换镜头：

- `对比并置`：把相反的动作、处境或价值放在一起，让观众自行得出判断。
- `平行/同步并置`：展示相互关联的同时事件，清楚区分空间并维持各自方向。
- `象征或主题蒙太奇`：压缩过程、建立主题或进入人物思维；每个画面必须服务同一命题。
- `组合剪辑`：用局部、动作和反应共同建构一个事件。先决定观众应感到震惊、悬念还是悲痛，再分配镜头时长和信息量。
- `场面调度长镜头`：当空间关系和表演变化本身足以推进剧情时，减少切镜，让权力转移在同一空间内发生。
- `交叉剪辑`：只有两条行动线存在因果、时间压力或主题碰撞时使用；每次切回必须升级一方状态。
- `分割画面`：适合必须同时看见的两方，不作为普通对话的装饰。
- `叠化`：用于柔化边界、关联两个意象或表现渐进变化；硬冲突通常不宜滥用。
- `跳切`：用于时间缺失、心理断裂、重复受阻或节奏突刺；必须保证观众仍能理解核心动作。

剪辑判断顺序：`观众此刻知道什么 → 下一条信息由谁拥有 → 何时揭示 → 切到哪里最有意义`。

## 五、时间：26—34

- `定调扩展时间`：在关键事件前加入环境、反应或细节，使等待本身产生压力。
- `时间对比`：把不同人物或空间的节奏并置，制造不平等、讽刺或迫近感。
- `动作重叠`：从不同角度重复动作的一部分，放大决定性瞬间；不得造成无意的重复或物理错误。
- `慢动作`：用于不可逆选择、主观感知或关键接触点，不等同于“高级感”。
- `快动作/省略`：压缩没有戏剧价值的过程，同时保留因果链和必要状态变化。
- `闪回`：由当前可见/可听触发物进入，并明确返回现实的锚点。
- `闪前`：用于预期、恐惧、愿望或结果预示，必须区分真实未来和主观想象。
- `定格`：强调不可更改的状态、记忆或判断；慎用于情绪高潮。
- `视觉时间提示`：用同一物件、场地、动作或构图的状态变化表现时间，而非依赖字幕说明。

时间变形必须回答“为什么观众要在这里感到更久、更短或失序”。

## 六、声音与音乐：35—41

- `现实声定位人物`：脚步、呼吸、器械、交通、房间反射等既交代空间，也能暴露身份和状态。
- `对声音的反应`：声音本身可普通，人物异常反应或不反应才揭示秘密。
- `表现性外部声`：把外界声音组织为压力、威胁、讽刺或情绪节拍，但仍保留合理来源。
- `超现实内心声`：用主观放大、过滤、错配或不存在于现场的声音表现记忆、愿望、幻觉和创伤；必须设置进入与退出依据。
- `歌词作为叙事者`：只在歌词真正补充人物或主题时使用；生产提示词描述音乐类型、情绪和叙事功能，不擅自指定受版权保护的歌曲。
- `音乐象征`：先建立音乐与人物、关系或命题的关联，再通过变奏、缺席或重现改变意义。
- `音乐作为移动道具`：让音乐有明确声源，并随人物或空间移动，承担连接场景或揭示距离的功能。

声音可先于画面进入形成声音桥，也可在高潮处突然撤掉形成有意义的静默。不要用背景音乐覆盖需要被听见的呼吸、停顿和动作反馈。

## 七、场景转换：42—51

转场应传递因果、时间、情绪或思想，不只负责“顺滑”：

- `匹配声音延续`：同一声音跨越切点，维持动作或情绪连续。
- `语言声音桥`：上一场尾句在下一场画面开始后完成，或下一场台词提前进入；确保说话者身份不会混淆。
- `音响声音桥`：用门响、铃声、机械声、环境声等连接两个空间，必要时通过声质变化提示已换场。
- `图形匹配`：相似轮廓或构图连接两场，新的场景必须在短时间内被重新定位。
- `图案/色彩匹配`：以重复色块或纹理建立主题关联，避免为了匹配改变已锁定服装和场景资产。
- `动作匹配`：上一场动作的方向、速度和作用点由下一场相似动作接续，可压缩时间或跨越空间。
- `思想匹配`：两个画面并置产生第三层意义；不要把隐喻解释成字幕。
- `延长匹配叠化`：用于时间流逝、年龄变化、记忆重叠或梦幻转换，需控制中间叠影的可读性。
- `中断匹配`：在前后匹配画面之间插入短反应或误导镜头，制造暂时疑问，再用更全信息解答。

为每个转场记录：`A场镜尾对象/声音/动作 → 切点触发 → B场承接对象 → 新时空定位信号 → 转场产生的新意义`。

## 转换为AI分镜提示词

导演层先输出叙事选择，模型适配器再翻译格式。单镜生成不应假装拥有后期剪辑能力；需要跨场匹配时，应分别锁定 A 镜尾帧和 B 镜首帧，并把声音桥或剪辑关系交给后期说明。

每个显著手法至少写出：

1. `目的`：观众应感到或理解什么；
2. `证据`：画面或声音中真正可见/可听的变化；
3. `执行`：机位、构图、动作、焦点、声音或切点；
4. `连续性`：人物位置、轴线、道具、光源与镜尾状态；
5. `停止条件`：达到目的后停止，不叠加无关技法。

## 校验问题

- 去掉台词后，关键关系或变化是否仍能被看懂？
- 技巧是否表达了当前剧情，而非展示导演存在感？
- 空间方向和参考图、俯视图、轴线是否一致？
- 转场是否产生新意义，并能在两个独立生成片段之间实现？
- 时间变形是否保留了动作因果和人物状态？
- 声音是否有来源、主观依据或明确的叙事功能？
- 是否把文化相关的方向符号误当成普遍真理？
