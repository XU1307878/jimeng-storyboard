# AI电影三系统生产闭环

本文件把外部案例中的资产、镜头和表演三类方法，转化为浩辉体系可复用的中文导演规则。它是跨平台工作方法，不携带 Higgsfield、即梦或 MiniMax H3 的专用语法。

## 一、三套系统的职责

### 1. 视觉资产系统

目的不是只做一张漂亮定妆图，而是让后续镜头调用同一个人物、场景和道具事实。

- 角色按剧情需要建立状态版本：基础、换装、湿身、受伤、污损、衰老、变身等；没有剧情变化则不滥建版本。
- 每个状态写明相对上一状态的唯一变化和保持不变项，避免换状态时连脸、体型、服装结构一起漂移。
- 场景建立入口、出口、固定家具、关键地标、可行动区域和真实光源；人物站位另行记录，不焊死在空场母版中。
- 道具记录归属、手别、接触点、状态变化和镜尾位置，避免复制、瞬移或换手。
- 参考素材一项只承担一个主要控制职责：身份、设计、场景、道具、首帧、动作、声音或风格。

### 2. 镜头执行系统

把导演意图转成生成模型可观察、可核验的镜头行为。

- 先确定剧情任务和动作地理，再选择景别、机位、焦段、运镜和切点。
- 每镜至少写清：首帧状态、主体动作路径、动作触发的主运镜、时间节拍、镜尾状态。
- 多人场景先确认参考图站位是否绑定；未确认时只写相对关系，必要时先给纯文本俯视图。
- 镜头切换必须新增动作、信息、情绪、空间理解或声音变化；不为“电影感”堆无效机位。
- 提示词完成后先审查空首帧、空间矛盾、素材职责冲突、动作过载、互斥运镜和无法承接的镜尾。

### 3. 行为表演系统

用行为呈现心理，不把“悲伤、紧张、愤怒”当成可直接执行的表演指令。

- 导演层使用：`触发 → 人物判断 → 对具体对象的当前目标 → 障碍与失败代价 → 当前策略/社会面具 → 行为泄漏 → 镜尾余态`。
- 模型层只保留可见或可听证据：动作、主表情、二至四个依次发生的微表情、呼吸和语气。
- 优先写动作动词和接触变化，例如松手、避视、吞咽、指腹加压、重心后撤，而不是重复情绪形容词。
- 当前策略失败、新信息进入或权力转移时才换拍；用动作中止、目线、呼吸、重心、距离或语速把换拍变得可见。
- 主体完成完整表演链，对手只给克制反应，背景人物按信息传播先后形成低幅度反应波，避免全员同时抢戏。
- 情绪和身体状态具有惯性；受惊、奔跑、受伤或强忍后的呼吸、姿态和手部压力必须带入下一拍。

## 研究吸收边界

本闭环参考公开AI长片工作资料中的资产、镜头与行为表演思想，只保留能被中文短剧生产验证的跨平台原则，并用本项目自己的结构重新表达。外部资料中的 Higgsfield 专属字段、英文固定模板、模型参数、绝对化成功承诺和未经本项目验证的数值不进入即梦或MiniMax H3适配层。

## 二、从剧本到生成的闭环

1. 导演研读：锁定事件、信息差、冲突、人物目标、情绪转折和镜尾义务。
2. 资产准备：只建立当前段落真正需要的状态版本、空间事实和道具连续性。
3. 镜头设计：用空间、动作、表演和声音把剧本节拍变成可见变化。
4. 平台编译：由用户选择的平台技能输出对应格式；跨平台方法不改变平台字段或接口规则。
5. 结果审片：按失败类型定位问题，只修失败层，不无理由重写已经成功的部分。
6. 连续性回写：若生成结果被采用，把新的可见镜尾状态回写到台账，再进入下一镜。

## 三、失败镜头最小补丁

每次失败先保存有效项，再修改一个主要变量。使用下列补丁卡：

```text
【失败镜头】：片段/镜头编号
【必须保留】：身份、构图、动作、表演、光线、声音中已经正确的部分
【失败类型】：身份／状态／空间／动作／表演／摄影机／光线／声音／文字
【可见证据】：具体哪里不对，不写“感觉不好”
【可能原因】：最多两个，区分提示词冲突与素材不足
【本轮唯一改动】：只改一个主要变量
【新的验收点】：下一次必须出现的可观察结果
【是否需要拆片】：是／否；若单镜任务过载则拆分
```

常用修正顺序：

- 身份或状态错：先检查素材职责和状态版本，不先改镜头语言。
- 空间或轴线错：回到已确认的场景事实、俯视图和首帧，不靠更多左右词硬压。
- 动作漏失或物理错误：减少同时任务，补起点、路径、接触点、受力结果和终点。
- 表演僵硬或夸张：把情绪名改成触发后的顺序行为，减少同时发生的五官信号。
- 运镜失控：只保留一个主运镜，明确由什么动作触发以及镜尾构图。
- 画面正确但剧情没发生：删除装饰性画质词，把主体、动作和结果前置。

## 四、验收原则

- 三套系统共享同一剧本事实，但各自只解决自己的问题。
- 资产正确不等于镜头成立，镜头漂亮不等于表演真实，表演细腻也不能改变剧情结果。
- 已成功的身份、空间、动作、表演、光线或声音层应被冻结；重试不得连带改坏。
- 平台专用限制始终由对应平台技能决定，本闭环不宣称任何模型参数或生成上限。
