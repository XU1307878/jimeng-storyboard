# 受众方向与平台节奏

## 受众判断

“男频、女频、泛受众、儿童家庭、海外女频”等是市场与代入路径，不是画面风格，也不能仅由主角性别判断。

需要判断时输出一张简洁卡：

- 受众方向：主方向 + 次方向；
- 主题材与辅助题材；
- 核心代入角色及观众站位；
- 欲望、阻力与承诺回报；
- 爽点、泪点、关系或谜题的主要兑现机制；
- 判断依据与置信度。

常见证据：

- 外部目标、能力成长、地位竞争、规则突破和胜负兑现通常强化目标驱动型代入；
- 关系选择、身份价值、情感主动权、安全感和自我确认通常强化关系与身份驱动型代入；
- 家庭安全、儿童成长、代际情感和现实公益往往属于泛受众或儿童家庭；
- 海外女频还需检查文化可读性、关系权力、婚恋契约、阶层与身份幻想，但不得自动套用霸总或囚爱套路。

混合项目允许“双主方向”，但要明确哪个方向控制视角和节奏。

## 平台节奏档案

仅在短视频、竖屏短剧、爆款开头、完播优化等留存导向明确时建立：

- 发布平台、画幅、目标时长；
- 当前节奏档位：电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏高信息；
- 前3秒任务：问题、异常、威胁、承诺或情绪伤口；
- 前15秒任务：建立人物处境、冲突、规则或关系变化；
- 前30秒任务：至少一次信息增量、情绪升级、目标改变或反转准备；
- 留白许可与功能；
- 结尾继续观看的理由。

不要把时间节点变成机械公式。慢镜头只要承担情绪、悬念、人物关系、空间信息、证据展示或下一拍蓄力，就可以保留。

## 处理差异

- 目标驱动型：优先明确任务、阻力、能力差、代价和结果，不用空泛旁白替代行动。
- 关系驱动型：优先明确关系距离、权力变化、潜台词和选择后果，不用反复误会拖延。
- 泛受众现实题材：优先事实清楚、人物可信、危险与解决路径可理解。
- 儿童家庭：危机可辨认、求助对象明确，不展示可模仿的作案流程。
- 海外向：先保证情节和人物动机的跨文化可读性，再处理语言和视觉包装。
