# 摄影机行为与动作物理

仅在动作、追逐、复杂调度或强运镜镜头中读取。普通文戏不为运动而运动。

## 先定动作，再定摄影机

动作必须形成可见链条：

`起势 → 接触点或能力作用点 → 受力结果 → 对方反应/自身代价 → 恢复动作 → 镜尾状态`

同时说明重量、重心、方向、阻力、道具接触、环境痕迹与双方最终距离。能力类动作还要说明来源、形态、作用对象、物理结果与残留。

4–8秒片段通常不超过3个主要打击或动作目标；10–15秒也要给反应、恢复或喘息留出可见时间。

## 摄影机行为句

不要只写“手持、跟拍、推镜”。至少明确：

`起始位置和景别 + 角色触发动作 + 摄影机路径与方向 + 速度/稳定程度 + 保持的空间关系 + 结束构图`

例如：摄影机位于人物右前方约一米、胸口高度中近景；人物转身奔跑时开始手持侧跟，速度与脚步同步，转弯短暂甩动后重新稳定，始终保持人物在画面右三分之一，最后停在门口全景。

## 镜头观察锚点前置

强运镜、复杂动作或容易误判动线的单镜头，先用一句话建立摄影机的起始观察坐标，再写人物动作。推荐顺序：

`起始机位/高度/景别/朝向 → 人物起始状态 → 动作路线与作用点 → 由动作触发的唯一主运镜 → 镜尾构图`

“前置”只前置当前镜头必要的观察锚点，不把所有镜头术语堆在开头。摄影机运动应由人物动作、视线或信息揭示触发，不能成为与动作并行的另一套无关指令。

不得宣称模型会像程序一样严格逐句执行提示词。语序用于降低语义竞争、尽早建立坐标和主任务，是生产启发式，不是确定性权重或执行保证。

## 选择原则

- 固定机位：对峙、审判、仪式、压住情绪；
- 缓推：真相逼近或注意力收束，必须说明推向眼睛、手或道具；
- 后拉揭示：从局部证据扩展到关系或空间后果；
- 横移揭示：多人站位或隐藏信息依次出现；
- 手持侧跟：追逐、逃亡和不稳定主观感；
- 前导退拍：人物逼近、边走边说或压迫增强；
- 视线摇镜：人物先发现，摄影机随后找到目标；
- 焦点转移：前景证据与后景反应之间的信息切换；
- 遮挡或甩镜切：只有遮挡来源、运动方向和新镜落点都明确时使用。

一镜只保留一个主导摄影机行为。禁止无动机漂移、随机变焦、越轴、跟丢主体、穿过实体、动作方向翻转和冲击后无结果。

## 动作空间与镜尾接力

- 动作先标清 `起点 → 移动通道 → 接触/作用点 → 终点`，再选择景别和摄影机路径；
- 构图为下一步主要动作保留必要负空间，只有动作确实需要更多空间时才后拉或放宽景别；
- 延后入场人物不得提前出现在背景，镜尾用动作、视线、道具、声音或负空间把下一镜引入；
- 下一镜的起始位置、身体惯性和道具接触必须继承上一镜落幅。
