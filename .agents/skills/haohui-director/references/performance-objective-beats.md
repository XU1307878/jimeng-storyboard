# 表演目标、策略与节拍

用于对白、近景、群像反应、情绪伪装和权力变化。它补足“动作—表情—微表情”的上游因果，不把抽象表演理论原样塞进视频提示词。

## 一、先确定可表演的任务

每个主要人物先在导演层回答：

`我现在要让谁做什么 → 对方或自己如何阻止 → 失败会失去什么 → 我此刻采用什么策略`

- 目标必须是指向具体对象的动作动词，例如逼对方承认、拖延回答、让对方留下、掩住破绽；“悲伤”“愤怒”“紧张”不是目标。
- 策略也是动作动词，例如试探、讨好、施压、回避、激怒、装作轻松、转移话题。策略失败后才换挡，不能整场只保持一种情绪强度。
- 人物只能表演当前已经知道的事实，不能从第一秒提前演出本场最终结果。

## 二、节拍变化必须可见

一个表演节拍在目标和策略暂时不变时持续。出现以下事件之一才换拍：

- 新信息进入；
- 当前策略失败；
- 权力关系改变；
- 人物做出决定；
- 关键动作被打断或完成。

每次换拍只选择一组可观察变化：目线先移、呼吸停顿、重心改变、手中动作中止、说话速度改变、距离被拉近或拉开。停顿中必须发生判断、压抑、决定或拒绝；没有行为内容的空停顿应删除或切镜。

## 三、动作、表情、微表情三层下发

导演因果：

`触发 → 判断 → 当前目标 → 策略/社会面具 → 身体动作 → 主表情 → 2—4个顺序泄漏 → 声音 → 镜尾余态`

模型载荷只保留能看见或听见的部分。优先顺序通常是：

1. 眼睛先找到或避开目标；
2. 呼吸、下颌或吞咽暴露处理过程；
3. 手部压力、重心或距离暴露真实选择；
4. 台词出口后保留未消失的余态。

特写越近，动作越少。近景主要依靠目线、眨眼质量、呼吸、下颌和口角；不要让整张脸同时夸张活动。需要潜台词时允许外在面具与身体泄漏相反，但必须来自同一目标。

## 四、让身体拥有正在做的事

对白人物应有与场景一致的身体任务，例如搅汤、整理文件、扣纽扣、擦杯子、握住门把。身体任务不是装饰：

- 动作如何完成，体现人物控制力与身份；
- 关键台词使动作突然停住，可以成为节拍标点；
- 道具接触必须连续，不能为了表演临时多出物件；
- 刚跑动、受伤或屏息的人，说话呼吸必须符合身体状态。

## 五、空间距离与地位

距离变化就是关系变化。人物靠近、后退、坐下、起身、转身或挡住出口，都要有明确目的，并继承已确认的空间事实。

- 高控制者通常动作少、反应慢、目光稳定、说话更轻；
- 低控制者可能频繁自触、抢答、碎笑、视线求许可；
- 最有价值的是短暂失态：强者一瞬慌乱，弱者突然停止讨好。失态后仍要保留状态惯性，不能下一拍自动复原。

这些是选择表演的线索，不是僵化的人物等级公式。

## 六、群像反应

- 群体反应按信息传播错峰发生，不让所有人同秒转头、同表情惊讶。
- 主体承担完整表演链，对手承担直接反应，背景人物只保留低幅度反应波。
- 关键威胁或真相出现时，可以用“原有小动作依次停止”制造安静，而不是让所有人继续忙乱。
- 延后入场人物不得借倒影、虚影或背景人群提前出现。

## 七、交付前检查

- 每位主要人物都有对象明确的目标、障碍、代价和当前策略。
- 换拍由信息、阻力、决定或权力变化触发。
- 反应可在对方台词结束前开始，但关键字和说话人口型仍清楚。
- 停顿里有可见处理过程；台词后有可继承余态。
- 三层表演互相支持，或明确构成“面具与泄漏”的有意反差。
- 群体反应有先后层级，特写没有五官堆叠。
