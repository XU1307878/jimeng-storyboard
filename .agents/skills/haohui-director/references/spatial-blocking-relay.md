# 空间调度与镜头接力

用于多人对话、固定座位、人物进出场、跨镜移动和需要为后续动作预留画面的场次。它是导演调度原则，不是任何生成模型的专属提示词语法。

## 先建立空间事实

按以下顺序确定，不能先凭构图习惯发明人物左右：

1. 场景边界与固定地标：墙、门、窗、桌椅、楼梯、出口；
2. 人物当前状态：位置、朝向、距离、遮挡、接触物；
3. 动作路线：起点、经过区域、交互或碰撞点、终点；
4. 摄影机可活动区、既有关系轴线与不可穿越实体；
5. 画幅裁切后仍必须保留的动作空间。

有参考图时，先确认参考图是否锁定站位；未确认的位置只能写成导演草案。复杂调度可用纯文本俯视图表达，简单场次不强制画图。

## 出镜人物门禁

每个镜头按需区分：

- `本镜允许出镜`：当前画面可见的人物；
- `延后入镜`：尚未出现的人物，并写明入镜方向与触发事件；
- `仅画外声`：可听见但不得被提前生成的人物。

人物尚未入场时，不得把他作为背景路人、倒影或虚化人影提前暴露。只有剧情刻意预告其存在时例外。

## 动作空间预留

人物移动必须形成 `起点 → 路径 → 作用点 → 终点`。构图应给即将发生的主要动作留出可见通道或负空间；必要时在动作前有动机地后拉、横移或切到更宽景别。不要为了“电影感”无理由拉远，也不要让画幅裁切切断路径或把人物移到未经确认的位置。

先在场景坐标中锁定真实路线，再将它转换为当前机位可见的屏幕动线：

`场景起点/地标 → 场景路径/终点 → 摄影机位置与朝向 → 画内进入方向/移动方向/离开方向`

屏幕左、右、前、后只描述当前镜头如何看见已确认路线，不能反过来改写人物真实站位。切换机位后重新换算屏幕方向，并保持场景终点、关系轴线和人物朝向连续。

人物起身、换位、入场或退场时，用状态切换表达：

`状态A（动作前） → 可见移动/切换依据 → 状态B（动作后）`

下一镜必须继承状态B，不能让人物、道具或家具无解释瞬移。

## 镜头接力

每个保留镜头应完成一个明确任务，并留下至少一个能触发下一镜的出口线索：

- 动作接力：身体运动或道具运动方向延续；
- 视线接力：人物先发现，下一镜揭示其所见；
- 声音接力：对白尾音、脚步、门响或画外声先行；
- 构图接力：为即将进入的人或物保留负空间；
- 状态接力：握持、坐姿、伤势、光源或距离被下一镜继承。

台词是否拆镜取决于可见目标、动作策略、信息归属或情绪权力是否改变，不按固定句数拆分。一个镜头若同时承担入场、长对白、反应和关系揭示而主次不清，应拆开。

## 交付前检查

- 固定家具是否错误插入人物之间；
- 延后入镜人物是否被提前看见；
- 路径是否穿过桌椅、墙体或其他实体；
- 动作终点是否成为下一镜可信起点；
- 景别是否真的容纳动作，而非仅追求运动；
- A/B机位是否服务当前关系，而非被当作固定公式；
- 简单场次是否被不必要的图表和机位规则拖慢。

## 不吸收的课程噪声

不把会议界面、聊天消息、绘图软件操作步骤、固定机位数量、示意画风或识别不清的口述句子写入导演规则。课程方法只在能转化为可验证的空间、动作与剪辑关系时保留。
