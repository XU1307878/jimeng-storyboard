# Routing Matrix

Select one primary mode by dramatic task, not merely by keywords. A secondary accent is allowed only when it adds a distinct function, such as using suspense information control inside a family-power drama. Never load all modes together.

## Selection rules

- Choose by the scene's dramatic engine: intimacy, procedure, ordinary life, temporal rupture, status reversal, grief, power hierarchy, rule discovery, uncertainty, action spectacle or comic failure.
- Use a visual label only after the medium is established. A suspense story can be live action, 2D or 3D; suspense does not imply photorealism.
- For hybrids, declare `primary + accent`, for example `family-power + suspense`. The primary mode governs rhythm and staging; the accent changes only the relevant information or visual beat.
- When no mode clearly fits, use `general-drama` and the core workflow. Do not force a genre preset.
- The user's latest explicit description overrides automatic routing.

## Common conflict resolution

- Aspect ratio conflicts: user/project choice wins; otherwise pending.
- Duration conflicts: target platform and user request win; source-module limits are historical notes only.
- Fixed lighting recipes: replace with motivated physical sources appropriate to the scene.
- Fixed camera ladders: replace with the minimum shot progression that communicates the beat.
- Named work or filmmaker references: convert into observable attributes and omit the name from production prompts.
- Conflicting story and style: story logic wins.
