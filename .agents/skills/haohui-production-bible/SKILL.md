# 浩辉生产资产台账

中文调用名：**浩辉生产资产台账**。内部调用标识：`$haohui-production-bible`。

## 目标与边界

- 把剧本事实转成可复用的文字资产和连续性契约，不代替导演设计剧情镜头。
- 默认不生成角色图、场景图、地图、首帧或道具图；只有用户明确要求时才进入实际资产制作。
- 不虚构发色、瞳色、服装、画面媒介或渲染技术。剧本未定义且不影响制作时只写角色名和剧情身份。
- 用户在本地画布手动 `@素材` 时，保持编号稳定并写清每张素材的唯一主要用途。

## 必读参考

1. 阅读 [references/asset-system.md](references/asset-system.md)。
2. 存在多人调度、反打、窗内外、柜台内外、车内外、关键道具或跨片段连续性风险时，再阅读 [references/continuity-cards.md](references/continuity-cards.md)。

## 工作方式

1. 读取定稿剧本或指定片段，提取角色、服装状态、场景、关键道具、时段和光源。
2. 建立稳定编号和版本，不因镜头变化重复创建同一资产。
3. 区分“设计参考、身份参考、场景参考、道具参考、首帧、尾帧、调度图、动作或运镜参考”，每项只设一个主要用途。
4. 对高风险场景建立文字空间包、侧别锁、调度点位或首帧需求卡。
5. 检查同一道具是否被场景图与独立道具图重复生成，必要时启用单实例锁。
6. 输出交给 `$haohui-director`、`$jimeng-storyboard` 或 `$minimax-h3-storyboard` 的精简交接包，不夹带目标模型之外的语法。

## 默认输出

1. `项目与版本`
2. `角色资产表`
3. `场景与光影表`
4. `关键道具表`
5. `素材编号与用途映射`
6. `高风险连续性卡`
7. `缺失与暂定项`
8. `下游交接包`
