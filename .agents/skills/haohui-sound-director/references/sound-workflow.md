# 后期声音工作流

## 声音层级

1. 空间环境：房间底噪、街道、风雨、人群、设备或自然声；
2. 同步动作：脚步、衣料、门、杯子、武器、碰撞和道具接触；
3. 人声：对白、旁白、呼吸、哭笑、画外声音；
4. 音乐：只在需要组织情绪、节奏、主题或段落关系时进入；
5. 静默：通过此前声音的撤离形成反差，不能仅写“完全无声”而没有功能。

## Cue Sheet字段

```text
Cue编号：
时间范围：
剧情功能：
进入/退出：
情绪轨迹：
速度与节拍：
音色与编制：
对白避让：
保留的环境声/关键音效：
禁止项：
```

## 音乐搜索与生成

搜索词至少包含：音乐功能、主要情绪、速度、音色/编制、是否无人声、使用空间和结构要求。

AI原创音乐提示词写：时长、功能、情绪起点与终点、速度、调性倾向、主要乐器、层次变化、高潮位置、结尾方式和禁止项。不要使用“某歌手同款”或具体作品名。

## 混音检查

- 对白是否始终可懂；
- 关键动作音是否被音乐遮住；
- 反转前音乐是否提前剧透；
- 情绪是否从一开始就满格；
- 突停和静默是否有前后对比；
- 相邻场景能否用环境声或尾音形成声音桥；
- 短视频结尾是否保留一句、一个音效或一次停顿作为声音钩子。
