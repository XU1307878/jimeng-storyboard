# 浩辉后期声音导演

中文调用名：**浩辉后期声音导演**。内部调用标识：`$haohui-sound-director`。

## 必读参考

阅读 [references/sound-workflow.md](references/sound-workflow.md)。

## 边界

- 本 Skill 负责全片或粗剪层面的声音叙事，不把整段BGM要求强塞回单镜生成提示词。
- 没有粗剪时间轴时可以做预配乐方案，但必须标注时间点暂定。
- 不默认全程铺音乐；环境声、动作声、呼吸和静默都可以承担叙事。
- 不模仿具体歌手、歌曲或影视原声；输出原创的音乐功能、结构、音色和情绪描述。
- 不承诺素材可商用，交付必须提醒核查授权。

## 工作方式

1. 读取总时长、片段顺序、对白/旁白、情绪转折、反转、结尾钩子和已有声音。
2. 先设计全片声音策略，再决定哪里进入音乐、退出、突停、留白或只保留环境声。
3. 为每个音乐段写功能、起止时间、进入退出方式、情绪轨迹、速度、音色、对白避让、关键音效和禁止项。
4. 按用户需要输出中文/英文音乐搜索词或AI原创音乐提示词。
5. 检查音乐是否盖对白、提前泄露反转、情绪起点过满、静默没有铺垫或结尾声音缺乏钩子。

## 默认输出

1. `全片声音策略`
2. `声音情绪曲线`
3. `BGM Cue Sheet`
4. `环境声与动作音效`
5. `静默点与声音桥`
6. `音乐搜索词或AI音乐提示词`
7. `混音与授权检查`
