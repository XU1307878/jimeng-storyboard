# 浩辉动态泼墨高燃打斗

本技能把水墨作为会参与动作和法术的动态介质，而非覆盖在普通3D画面上的灰度滤镜。

## 路由边界

- 用户要高速打斗、泼墨爆炸、书法速度线、人物墨化、黑白朱砂、墨龙、剑阵或法术粒子时，使用本技能。
- 用户明确要写实3D人物、PBR材质、水墨只用于远山云雾、节奏克制或文气留白时，使用 `linglu-jianlai-ink-animation`。
- 用户只要普通3D仙侠法术而不要求动态水墨介质时，使用 `linglu-xianxia-combat`。
- 用户的画幅、时长和平台要求优先；不要把其他技能示例中的15秒或16:9限制带入本任务。

## 创作原则

1. 先锁定角色、武器、战场、主色、运动轴、画幅、时长和胜负结果。
2. 水墨必须进入六层：人物边缘、动作残影、剑气轨迹、法术形态、环境破坏、镜头转场。缺少三层以上时，判定为“灰度古装”，不是动态水墨。
3. 色彩默认以宣纸白、浓墨黑和朱砂红为主；可按用户设定增加一种辅助能量色，但不能变成彩虹光污染。
4. 高燃节奏采用“0帧入战 → 连续拆招 → 术法升级 → 巨物压迫 → 天地对撞 → 结果落地”。除非用户要求蓄势，前3秒必须出现攻击、闪避或碰撞。
5. 高速动作占主要时长，慢动作只服务关键接触、反转和终结。每次停顿约0.2—0.5秒，停后立即恢复高速。
6. 每个动作写清意图、路线、接触、受力和终点。高速不等于模糊；脸、持剑手、武器形状和接触点必须可辨认。
7. 每2—4秒至少改变一项：攻击方式、空间高度、法术层级、体量关系、镜头方向或环境状态。避免连续数秒压剑、站立、慢走或重复挥砍。
8. 每个高潮至少组合两种放大器：体量压迫、数量爆炸、违背重力、天地对撞、介质变形、环境响应。
9. 特效必须有生命期：生成来源 → 汇聚方式 → 运动路径 → 接触反应 → 衰减或残留结果。不能只写“粒子特效拉满”。
10. 镜头运动跟随攻击几何。每镜只设一个主运镜，并写明起点、方向、加减速、跟随对象、停点和镜尾。

## 动作优先与复杂度预算

生成模型会优先完成容易呈现的造型、巨物和光效，并压缩真正的攻防过程。设计前先做复杂度预算：

- 先写可执行的身体动作，再叠加水墨介质、法术和运镜；不得用“大场面”替代交手。
- 一个连续时间段只承担一个主要动作任务。每组交锋必须完整经过“起势 → 攻击路线 → 判断 → 闪避或格挡 → 接触 → 双方受力 → 空间位置改变”。
- 30秒连续生成默认控制在3组完整攻防、1个主法术、1次体量升级和1次终结碰撞；只有模型能力或用户素材足以支撑时才增加复杂度。
- 同一时刻最多保留一个主要攻击、一个防守反应和一个主特效。法相、剑阵、墨龙等高复杂元素不要并发出现。
- 先锁一条主运动轴；改变高度或轴线时，用追击、遮挡或明确落点完成过渡，不能让角色无因换位。
- 动作与特效冲突时，保留人物轮廓、兵器接触、受力和结果，主动削减粒子数量、背景异象和镜头运动。
- “高速”通过短促步法、清楚轨迹、立即反应和连续位移体现，不通过全程运动模糊、抽帧或无重力乱飞体现。
- 每个动作块结束后才能进入下一块；提示词明确禁止省略格挡、击中、受力或落点。

## 输出结构

按用户需要输出完整提示词或分镜，至少包含：

1. 视觉介质锁定：二维水墨、二维与2.5D混合，或用户指定形式。
2. 黑白朱砂等色彩规则与材质规则。
3. 人物、武器、站位、运动轴和空间层次。
4. 按时间或 cut 设计的动作、法术、粒子、环境响应和运镜。
5. 关键碰撞的短暂停顿与恢复高速节点。
6. 镜尾状态及下一镜继承条件。
7. 与当前失败风险直接相关的负面提示词。
8. 可观察的验收点。

若用户要可直接复制的长时文生视频提示词，先输出一条全局动作优先级：发生冲突时优先保留完整攻防和因果，依次削减背景粒子、环境异象、次要法术和复杂运镜。

## 交付前验收

- 第一眼能否看出水墨介质，而非黑白滤镜？
- 人物高速运动时是否产生飞白、墨滴或笔触残影，停止时是否重新凝实？
- 是否同时存在清楚的近身攻防和至少一种完整法术？
- 粒子、墨雾和强光是否保留主体剪影与接触点？
- 环境是否随威能出现裂桥、倒卷云海、悬浮碎石、山体墨化等结果？
- 30秒内容是否持续升级，而非前快后慢或长期重复同一动作？
- 终结招是否改变敌人和环境，并给出可见胜负结果？
- 是否出现“招式名称很多但人物没有真正交手”的海报式打斗？若有，删除次要法术并补齐接触、受力和位移。
- 任一时刻是否同时要求两个以上巨型法术、复杂变身和复合运镜？若有，降低复杂度后再交付。
