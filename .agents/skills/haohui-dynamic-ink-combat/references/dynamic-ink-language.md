# 动态泼墨打斗执行语言

## 风格识别

动态泼墨不是“3D人物加灰色滤镜”。画面中的运动、能量和破坏都要改变水墨介质：

- 人物：静止时轮廓凝实，高速移动时衣摆和身体边缘散成墨滴、枯笔飞白与书法拖尾。
- 武器：实体轮廓清楚，挥动路径形成粗细变化明显的飞白笔锋。
- 法术：由墨粒、朱砂、纸纤维、液态墨流、笔触碎片和半透明气流构成。
- 环境：群山、云海、桥面、树木可以被剑气擦除、晕染、撕裂、卷起或重新落墨成形。
- 转场：使用墨汁遮屏、剑刃掠屏、笔锋横扫、纸面撕裂、瞳孔墨化和粒子聚散。

## 视觉层级

| 层级 | 作用 | 写法 |
|---|---|---|
| 宣纸底 | 统一画面呼吸 | 可见轻微纸纤维与吸墨边缘，避免复古黄滤镜 |
| 焦墨主体 | 保证动作可读 | 人物与武器接触点使用最深墨色和锐利边缘 |
| 淡墨空间 | 建立纵深 | 远山、云海与烟雾按距离逐层减淡 |
| 飞白动势 | 表现高速 | 粗粝断续笔锋沿攻击路径延伸，方向必须一致 |
| 墨滴粒子 | 表现能量与撞击 | 粒子从明确来源喷出，遵循冲击方向和衰减 |
| 朱砂点睛 | 锁定视觉爆点 | 用于血月、衣带、符文或敌方能量，不能平均铺满 |

## 高燃时间结构

30秒连续片段的推荐密度，可随剧情调整：

```text
0—3秒：0帧入战，首个兵器接触或致命追击
3—8秒：3—5次可读的高速拆招，建立双方能力差
8—13秒：第一次法术追杀，改变高度或运动路线
13—18秒：主角反击，人物或武器发生墨化变形
18—23秒：反派巨物法相或大范围术法形成体量压迫
23—27秒：数量爆炸与天地对撞，短暂停顿后核爆级释放
27—30秒：终结穿透、敌人崩解、环境结果和收势
```

高速动作通常占70%—85%。关键碰撞、局势反转和终结分别使用一次0.2—0.5秒短暂停顿。避免超过1秒的连续定格，除非用户明确要写意留白。

## 动作编排

每组拆招保持可追踪：

```text
攻击者转胯或踏步起势 → 武器沿清晰弧线进攻 → 防守者视线捕捉攻击 → 格挡或闪避 → 接触点爆出墨粒和飞白冲击 → 双方受力分离 → 一方借环境立即进入下一招
```

高速段可以使用下腰、侧翻、贴地滑行、踏碎石借力、空中换手、擦身交错和连续追斩，但每镜只保留一个核心动作。攻击轨迹、运动方向和双方终点必须清楚。

### 动作块编译法

先用无特效语言写动作骨架，确认因果完整后再添加水墨层：

```text
骨架：重剑横斩 → 女剑客下潜滑步避开 → 借滑步斜撩反击 → 对手竖剑格挡 → 双剑接触 → 双方沿相反方向分离
水墨层：横斩留下粗重焦墨笔锋；接触点沿受力方向喷出黑白墨滴；滑步在桥面留下细长飞白剑痕
摄影层：低机位侧移锁定，只跟随两人横向位移；碰撞时急停0.25秒，随后沿反作用方向震退
```

不要把三层同时自由发挥成一串形容词。动作骨架是不可删减层；水墨层与摄影层必须服务于它。

### 30秒复杂度上限

长时连续生成优先采用5个动作块，而不是大量碎镜头：

1. 近身首轮：3—4次可读拆招，建立力量与速度差。
2. 追击换位：一次地面或空中追杀，改变高度或距离。
3. 法术反制：一个主法术完成来源、路径、接触和消散。
4. 体量升级：双方各保留一个清晰攻击形态，形成对冲方向。
5. 终结结果：碰撞、短暂停顿、释放、敌我状态和环境后果。

默认不要在同一片段同时使用墨龙、万剑阵、完整巨人法相、多人围攻和多次变身。若用户要求全部出现，拆为两个片段或让其中若干只作为远景背景，不承担动作因果。

### 接触与受力检查

每次关键攻击至少能回答：

- 谁先动，攻击从哪侧进入？
- 对手何时看见并如何应对？
- 武器或法术在哪里接触？
- 接触后谁的重心被破坏，身体朝哪边移动？
- 地面、衣摆、碎石和墨滴是否沿同一受力方向响应？
- 下一招是否从上一招的落点自然开始？

缺少任一项时，优先补动作因果，不增加新法术。

## 法术设计

每个法术回答五个问题：

1. 从何处产生：剑尖、掌心、地面裂缝、影子、血月或符印。
2. 如何汇聚：墨粒逆流、朱砂线缠绕、碎石悬浮、云海形成旋涡。
3. 如何运动：追咬、倾泻、旋切、穿刺、合围或坠落。
4. 接触后发生什么：泼墨冲击、宣纸撕裂、墨色擦除、敌人碎裂、山体晕散。
5. 结束留下什么：裂桥、墨雨、断月、消散法相、残余符文或能量余烬。

可用法术：墨龙追杀、万剑书阵、朱砂符链、泼墨巨掌、黑甲法相、纸鹤剑群、墨海倒卷、山河卷轴封印、血月断裂。

## 运镜语法

- 贴地冲镜：沿桥面或地面向战斗核心加速，碎石与墨滴从前景掠过。
- 侧移锁定：摄影机与角色横向同步，适合连续拆招和追击。
- 甩镜接招：跟随上一击方向快速摇摄，在新构图中找到下一位攻击者。
- 穿缝推镜：从剑刃、巨口、法印或飞剑阵缝隙穿过，进入下一空间层。
- 低机位仰推：拉出巨物、法相、血月或遮天剑阵。
- 高空俯冲：表现剑雨、巨掌或法术倾泻的势能。
- 主观飞行：贴随一柄剑、一颗墨滴或一条墨龙高速穿行。
- 超远景急拉：在碰撞前后揭示体量和环境破坏规模。
- 碰撞急停：摄影机与动作同时停0.2—0.5秒，随后沿反作用方向释放。
- 遮挡切：让剑刃、墨浪或强光短暂遮满画面；遮挡前后保持动作方向。

每镜选择一个主运镜。运镜描述需包含触发点、方向、速度变化、主体和停止位置。

## 粒子与介质生命周期

不要只写“粒子拉满”。示例：

```text
剑刃接触时，从接触点沿受力方向喷出细密银白碎芒和黑色墨滴；近处粒子高速掠过镜头，远处粒子受风旋转上升；0.8秒后亮度衰减，墨滴落在桥面形成向右延伸的泼墨痕迹。
```

```text
掌心朱砂符线先绕腕旋转，随后吸引周围墨粒汇聚成球；出掌时能量球拉成长梭并留下断续飞白拖尾；撞击法相后爆成环形朱砂冲击波，波纹扫过云海并把山体边缘染成扩散墨晕。
```

## 容易失败的方向

- 普通3D古装人物套黑白滤镜。
- 水墨只出现在远山和云雾。
- 整段只有物理挥剑，没有完整法术生命周期。
- 以慢走、摆姿势、长期压剑代替打斗。
- 全程运动模糊，持剑手、武器和接触点不可辨认。
- 粒子没有来源、路径和结果，只在画面中随机飘浮。
- 巨型法相出现后没有与人物发生接触或改变环境。
- 强光、墨雾或碎片完全遮住高潮动作。
- 红色平均分布，失去朱砂点睛作用。
- 同时堆叠多种法术、巨物、变身和复合运镜，人物只剩摆姿势。
- 用镜头旋转、震屏、抽帧和运动模糊伪装高速，实际没有追击、闪避和受力位移。
- 连写招式名称或“连续对打”，却没有逐招说明攻击路线、接触点和结果。

## 验收点

正常速度观看时，下一版必须同时满足：

1. 前3秒发生首次攻击或碰撞。
2. 8秒前完成至少三次方向清楚的攻防变化。
3. 15秒前出现一次具有生成、路径、接触和结果的法术。
4. 23秒前完成一次体量或数量升级。
5. 高潮中存在可见粒子、飞白、墨流和环境响应，主体仍清楚。
6. 末3秒给出敌人状态、环境破坏和主角镜尾姿态。
7. 任意抽取三帧，都能从人物或特效边缘认出动态水墨，而不是灰度3D。
8. 至少三次关键接触均能辨认攻击方、防守动作、接触点、受力方向和落点。
9. 删除全部特效描述后，动作骨架仍能构成一场连贯的打斗；否则说明仍在用特效代替动作。
