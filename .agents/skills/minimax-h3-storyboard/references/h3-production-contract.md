# MiniMax H3 导演生产协议

## 适用范围

本协议控制 `$minimax-h3-storyboard` 的导演研读、镜头设计和跨片段连续性。它不宣称未经确认的 H3 界面能力。用户提供的具体 H3 参数优先；Ref2VA 的最终编译另见 `h3-ref2va-contract.md`。

## 提示信息优先级

按以下语义顺序组织每个生成片段：

1. 当前片段实际引用的素材及其唯一控制属性。
2. 时长、分辨率、画幅、媒介形式和已确认风格。
3. 可见主体、起始关系、朝向、视线、接触和道具状态。
4. 按时间推进的动作与三层表演。
5. 景别、机位和一个主要摄影机行为。
6. 有来源的光线、材质与必要环境反馈。
7. 对白、环境声和同步动作声。
8. 可见且可承接的镜尾状态。
9. 少量针对本镜风险的负面约束。

关键词重复和未经确认的数字权重不能替代清楚的动作优先级。片段内存在过多竞争动作时应拆分，而不是堆叠形容词。

## 导演分镜版片段头

```text
【模型】：MiniMax H3
【生成片段】：Clip 01（总时长：__秒）
【画幅与画面形式】：__
【出场人物】：__
【出现场景】：__
【关键道具】：__；没有则写“无关键道具”
【素材映射】：仅列真实提供且本片段实际使用的素材；没有则省略
【空间关系】：已由参考图确定／待用户确认／纯文本俯视图编号
【光线母版】：__
【声音母版】：无背景音乐或配乐方向；环境声；动作声
```

## 导演分镜版内部镜头

```text
【镜头编号】：Shot 01（时长：__秒）
【剧情任务】：本镜新增的信息、情绪或动作结果
【出场人物】：__
【出现场景】：__
【关键道具】：__
【空间与轴线】：只写已确认的相对关系、视线和摄影机允许区域
【运镜景别】：景别、机位高度、角度、镜头类别；一个主运镜
【镜头衔接】：承接上镜的可见入点；本镜可见出点
【首帧状态】：姿态、视线、接触、道具、前中后景和光源
【动作】：身体行为、接触、发力、重量和最终姿态
【表情】：可读的主要情绪或社会面具
【微表情】：2—4个按因果顺序发生的眼神、眉眼、口角、下颌、呼吸或手部压力变化
【画面提示词】：按优先级组成可执行生成段落
【配音与声音】：角色｜年龄或音色｜目标｜气息、音量、语速、停顿｜原文台词；环境声；动作反馈声
【负面提示词】：只写本镜高风险错误
【镜尾】：最后0.5—1秒可见状态，供下一镜承接
```

## 表演因果

导演推理可以使用心理目标，但生成文字必须给出可观察证据：

```text
触发 → 0.2—0.8秒判断延迟 → 身体策略 → 可读表情 → 2—4个微反应 → 声音行为 → 镜尾余态
```

- 动作层：姿态、重心、距离、手部接触、道具和结束位置。
- 表情层：一个主要情绪，或角色刻意维持的社会面具。
- 微表情层：通常先眼神，再呼吸、下颌或口角，最后由手部压力泄漏；不要所有信号同时爆发。
- 声音层：气息、音量、速度、音高走向、停顿和咬字与当前目标一致；若角色在伪装，则写清表面声音与泄漏反应的反差。

## 空间确认与轴线

- 参考场景图优先于文字推断。不得为了套用轴线模板移动门、桌椅、人物或摄影区域。
- 人物站位已由参考图明确时，记录为场景事实，不再重新设计。
- 站位未知且镜头依赖左右关系时，先输出纯文本俯视图并等待确认；用户允许自由设计时再锁定。
- 未确认阶段可以写“朝向对方”“看向门口”“保持上一镜方向”，不要擅自写绝对画左或画右。
- 正反打只改变观察角度，不改变人物、道具、光源和入口出口的真实位置。

## 摄影机语法

按剧情功能选择运动：

- 静止：克制、观察、尴尬、压迫或让表演自行产生张力。
- 推近：认知收窄、压力上升、决定或情绪泄漏。
- 拉远：孤立、后果、关系破裂或环境揭示。
- 横移、摇摄、跟拍：维持动作地理或把注意力交给新主体。
- 手持：身体性焦虑与不稳定；幅度必须受控。
- 环绕：权力关系改变或空间揭示；近景大幅环绕容易破坏脸和轴线，应慎用。

运动写成：`起始构图＋主体触发＋摄影机路径＋速度或缓急＋持续保持的空间关系＋结束构图`。

## 光线连续性

明确可见或合理存在的光源：窗、顶灯、门口、街灯、手机、火焰或天空。相邻镜头保持：

- 主光的屏幕侧和高度；
- 软硬、色温和人物曝光；
- 眼神可读性与投影方向；
- 人物和背景的明暗关系。

反打不能让光源自动换边。只有画内光源事件、人物进入另一光区或明确换场才能改变光线。

## 声音结构

按需使用三层：

1. 建立地点与时间的环境声。
2. 与接触、脚步、衣料、武器、道具和环境反应同步的动作声。
3. 对白、旁白或画外提示。

让至少一个声音参数在片段中发展，例如距离、响度、混响或密度。用户要求无BGM时，不添加随机音乐。

## 连续性检查

- 片段与内部镜头时长合计正确。
- 人物身份、服装、发型、伤势和污渍稳定。
- 道具保持正确持有者、手别、位置和状态。
- 上镜镜尾与下镜首帧在姿态、视线、接触和运动阶段上相等。
- 入口、出口、视线和屏幕运动方向符合已确认空间。
- 光源没有无因换边、变色或跳亮。
- 对白适配时间，且说话者正确、原文完整。
- 生成画面不出现字幕、水印、对话框或无意可读文字。

## 失败镜头局部修复

H3重试仍使用本技能规定的导演分镜版或Ref2VA四字段格式，不引入其他平台语法。修复前先冻结已经正确的身份、状态、空间、动作、表演、摄影机、光线和声音层，然后记录：

`必须保留的成功项 → 失败类型 → 可见错误证据 → 本轮唯一改动 → 新的可观察验收点`。

- 身份或状态错误：优先修正素材定义与状态版本。
- 空间或轴线错误：回到参考图或已确认纯文本俯视图，修首帧关系。
- 动作遗漏或接触错误：减少并行动作，补起点、路径、接触点、受力结果和终点。
- 表演僵硬或过度：用先后发生的行为替代情绪形容词，只保留二至四个决定性信号。
- 摄影机混乱：保留一个主运镜并明确触发与镜尾构图。
- 任务过载：拆成独立片段，不用更多关键词硬塞。

## H3边界检查

- 模型字段为 `MiniMax H3`。
- 导演分镜版不伪造 Ref2VA 标签；Ref2VA 执行版严格使用四字段。
- 没有即梦或 Seedance 专用界面语法。
- 没有把未确认的 H3 时长、权重、素材数量或参数写成官方事实。
- 外部资料只影响导演知识，不改变用户选择的模型和输出格式。
