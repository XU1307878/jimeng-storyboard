# MiniMax H3 分镜导演

先导演研读，再把既定剧情编译成 H3 可执行提示词。保留人物、事件、动作顺序、台词、结果和限制条件，只补足能够被镜头观察到的空间、动作、表演、摄影机、光线、材质与声音细节。

## 模型边界

- 只在用户明确指定 `MiniMax H3`、`H3` 或 `$minimax-h3-storyboard` 时启用。
- 不加载或输出即梦、Seedance、Runway、Higgsfield 等平台专用语法。
- 本技能吸收的 Ref2VA 结构来自用户提供的 H3 技能包，不冒充官方文档。界面能力、时长上限、分辨率选项和素材数量限制如未被用户或当前界面确认，标记为“需在H3界面确认”。
- 不实际生成图片或视频，除非用户另行明确要求。

## 必读与按需参考

1. 每次使用都完整读取 [references/h3-production-contract.md](references/h3-production-contract.md)。
2. 用户提供 `@图N`、`@视频N`、`@音频N`，或明确要求“全参考”“Ref2VA”“可直接复制到H3”时，再读取 [references/h3-ref2va-contract.md](references/h3-ref2va-contract.md)。
3. 涉及打斗、武器、追逐、法术、变身或复杂特效时，再读取 [references/h3-action-vfx-compiler.md](references/h3-action-vfx-compiler.md)。

## 先确定交付模式

### A. H3全参考执行版

适用于用户提供真实素材句柄，或明确要求 Ref2VA 可复制提示词。

- 最终执行提示词只包含 `subject_definitions`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 四个字段。
- 导演研读、语义锁定、空间账本和连续性检查在内部完成，不混入四字段。
- 用户要求中文审阅版时可输出中文正文；默认执行版使用英文正文，台词、歌词和画面文字保持用户指定的原语言。
- 用户若同时要导演说明，可先给简短审阅说明，再单独给一个无杂项的四字段复制块。

### B. H3导演分镜版

适用于用户要求研读剧本、讨论分镜、规划多片段或制作生产文档，但尚未进入全参考投喂。

- 使用制作摘要、场次事实表、生成片段、内部镜头和连续性检查结构。
- 不虚构 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 或平台参数。
- 一旦用户要求最终 Ref2VA 提示词，再把已确认的导演方案编译为模式 A，而不是把两种格式混写。

## 工作流程

1. 完整阅读所请求的剧本或场次，判断题材、受众、情绪主线、冲突、信息揭示与镜头节奏。
2. 提取时长、分辨率、画幅、媒介风格、人物、场景、道具、台词、动作节点、情绪转折、声音限制和结尾状态。
3. 建立内部语义锁定清单：人物身份与关系、地点、初始状态、事件顺序、动作对象、道具归属、接触结果、胜负或情绪结果、全部原始台词和负面限制。
4. 用户已指定镜头数量、时间段、景别、机位、构图、运镜和顺序时优先保留；信息缺失时才做导演级补全。
5. 若参考场景图已经确定空间，不凭空改写人物站位。站位不明确且会影响轴线时，先给纯文本俯视图或向用户确认；未确认前使用相对关系，不宣称绝对画左画右。
6. 按说话人变化、动作目标、揭示、情绪转折、地点变化或生成连续性风险拆分。镜头和片段时长服从剧情及用户选择，不把未经确认的平台限制写成事实。
7. 每镜只设一个主要叙事任务、一个主要摄影机行为、一个可读的表演变化和一个可测量镜尾状态。
8. 表演按因果编译：`触发 → 短暂判断 → 当前目标 → 身体策略 → 表情 → 2—4个微表情泄漏 → 声音表现 → 镜尾余态`。
9. 光线写成可执行关系：`真实来源＋屏幕侧与高度＋方向＋软硬与色温＋人物效果＋背景关系`，反打不改变光源方向。
10. 完成素材真实性、对白保真、时长、人物、道具、空间、动作、光线、声音和模型边界检查后交付。

## 语义保护

- 允许补充：空间位置、动作过渡、发力和反作用、微表演、服务既定事件的镜头、材质光线、环境反馈与同步声音。
- 禁止增加：未获授权的新人物、新关键道具、新台词、新剧情、新招式、新冲突、新转折、新伤势或新结果。
- 对白逐字保留，不改写、不翻译、不删减、不补写、不合并、不重排、不调整标点。若自然语速与片段时长冲突，先指出冲突并让用户决定时长、台词或表演语速。
- 构图增强只决定既定事件如何被看见，不能改变参考图已确定的场景结构或人物关系。

## 质量标准

- 人物动作、表情、微表情和声音来自同一心理因果，不互相打架。
- 手、武器和关键道具写明持有者、手别、接触点、重量传递和最终位置。
- 遵守180度轴线；跨轴必须通过可见摄影机路径、人物穿越轴线或中性建立镜头重建方向。
- 一个短镜头优先一种主运镜；写清起始构图、触发、路径、速度或缓急、保持关系和结束构图。
- 生成画面默认无字幕、无水印、无对话框和无意可读文字；后期文字与生成画面分开说明。
- 优先正向描述物理目标，再写少量与本镜风险直接相关的负面约束。
- 不重复关键词，不使用未经H3确认的数字权重模拟优先级。

## 默认交付

- 默认交付 UTF-8 Markdown 或 TXT 文本。
- 只有用户明确要求时制作 DOCX。
- 不制作 HTML、图片、视频、分镜图或其他渲染资产，除非用户明确要求。
