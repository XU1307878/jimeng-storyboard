# 浩辉成片审片

中文调用名：**浩辉成片审片**。内部调用标识：`$haohui-video-review`。

## 边界

- 先看用户实际提供的视频、抽帧、参考图、剧本或原提示词，再下结论；没有看见的画面不猜。
- 只诊断与提出最小修复方案，不默认修改视频、资产、剧本或平台提示词。
- 不用审美形容词替代证据。每项问题写明时间码、可见表现、违反的既定事实和影响。
- 保留已经成功的身份、空间、动作、表演、摄影机、光线与声音层，禁止整段无差别重写。
- 平台格式由对应技能处理：即梦交给 `$jimeng-storyboard`，MiniMax H3交给 `$minimax-h3-storyboard`。

## 必读参考

1. 阅读 [references/review-rubric.md](references/review-rubric.md)。
2. 需要重跑建议时，再阅读 [references/repair-card.md](references/repair-card.md)。

## 工作流程

1. 确认审片依据：成片文件、目标剧本/分镜、人物与场景参考、目标平台和用户特别关注点。
2. 读取视频元数据；按镜头边界、动作峰值、对白起止和疑似错误点抽查画面。必要时生成联系表，但不把抽帧当成完整运动证据。
3. 先做整体观看，记录叙事是否看懂、情绪是否成立、节奏是否断裂；再做逐镜技术检查。
4. 按严重度分类：`阻断`（剧情或身份错误）、`严重`（连续性/空间/动作明显错误）、`一般`（表演和质感降低）、`可接受`。
5. 每个问题只归入一个主失败层，必要时注明次要影响，避免重复计数。
6. 输出“必须保留的成功项”和“本轮唯一主要改动”。只有镜头任务过载或错误跨越多层时才建议拆片。
7. 给出验收点：下一版必须出现的可观察结果。无法从现有材料判定时标记`证据不足`。

## 默认输出

1. `审片结论`
2. `依据与限制`
3. `通过项`
4. `时间码问题表`
5. `最小修复卡`
6. `建议重跑范围`
7. `下一版验收点`

除非用户要求，不输出后期剪辑方案。
