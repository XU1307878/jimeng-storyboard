# AI成片审片量表

## 检查层

| 层级 | 通过标准 | 常见失败证据 |
|---|---|---|
| 剧情与信息 | 事件顺序、说话人、揭示和结果符合定稿 | 漏事件、错台词、提前揭底、结果被改写 |
| 人物身份与状态 | 脸、体型、发型结构、服装版本、伤势状态连续 | 换脸、换装、伤势消失、同人复制 |
| 场景与空间 | 门、桌椅、地标、人物真实点位和行动路线稳定 | 家具移动、椅子穿人、人物瞬移、入口换边 |
| 轴线与视线 | 已建立的关系轴和摄影机侧可追踪；正反打目光互相匹配；连续动作的银幕方向保持一致，或转身/折返/换侧过程可见 | 无交代越轴、人物左右互换、互看同向、视线高度错误、切点前后运动方向倒退 |
| 动作与接触 | 意图、攻击线路、防守选择、接触、受力、结果和恢复完整 | 手穿物、无接触受击、防守无察觉线索、重量消失、结果未落地就切镜 |
| 表演与口型 | 目标、策略换挡、动作、主表情、微表情、呼吸和台词同源，状态具有惯性 | 情绪贴纸、提前演结局、全脸夸张、群体同步反应、口型错人、嘴动无声 |
| 摄影机 | 主体清楚、主运镜单一、构图服务当前节拍 | 漂移、无因变焦、跟丢主体、近景大环绕变脸 |
| 光线与材质 | 光源方向、摄影机相对光源侧、色温、曝光优先对象与阴影跨镜稳定 | 反打换光、曝光目标冲突、闪烁、材质融化、无来源光束 |
| 声音 | 对白可懂、动作同步、环境空间一致、静默有意图 | 声画错位、音色漂移、混响跳变、BGM压对白 |
| 镜头衔接 | 上镜镜尾可成为下镜首帧，动作和声音连续 | 姿态跳变、道具换手、动作阶段倒退、环境声断裂 |

## 严重度

- `阻断`：改变剧情、人物身份、胜负、关键信息或使镜头无法使用。
- `严重`：观众明显察觉空间、动作、口型或连续性错误，需重跑。
- `一般`：不改变理解但削弱表演、节奏或质感，可按成本决定。
- `可接受`：存在轻微生成痕迹，但正常播放速度下不影响观看。

## 取证规则

- 每项关键结论注明`直接观察`、`用户报告`、`计划状态`或`待确认`。只有实际观看视频或连续帧才能标为直接观察。
- 运动错误必须结合连续帧或实际播放判断，不能只凭单张抽帧。
- 口型至少检查台词开始、关键词和结束三个阶段。
- 空间问题优先与确认的参考图或俯视图比较；没有空间锁时只判断镜内自洽。
- 判定越轴前先确认前镜已经建立关系轴或运动轴。可见越轴、轴线上的中性镜头、重新建立空间的宽景或明确的新动作轴不算错误；只在换侧造成位置、视线或运动方向误读时记为失败。
- 审片前核对提示词中的 `@` 编号是否对应真实上传文件。只有占位符而没有实际素材时，不判定模型“忽略参考”；人物、场景、道具和声音只能按无参考基准审查。
- 文字道具分别检查版式继承和逐字准确性。普通参考图生效不等于运动中的汉字已经保真。
- 不把原提示词要求但画面不可见的抽象目标判为失败。
- 文件时间最新不等于已选片段。审片可给采用建议，只有用户确认后才提取实际镜尾并更新连续性。
