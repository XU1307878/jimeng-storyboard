# 制片路由与阶段门

| 用户目标 | 主Skill | 可选辅助 | 完成条件 |
|---|---|---|---|
| 从零写故事、改编小说或续写 | 小说转AI漫剧 | 浩辉剧本会诊 | 文本结构满足用户范围；不产生分镜 |
| 判断剧本问题、钩子或男女频 | 浩辉剧本会诊 | 浩辉台词诊断 | 问题有剧本证据和修改优先级 |
| 精修对白、区分角色声音 | 浩辉台词诊断 | 浩辉剧本会诊 | 不擅改剧情，语速和表演可执行 |
| 导演研读、风格、节奏和镜头设计 | 浩辉短剧导演 | 浩辉生产资产台账 | 剧情任务、调度、表演和镜尾明确 |
| 人物/场景/道具/空间连续性 | 浩辉生产资产台账 | 浩辉短剧导演 | 编号、状态、空间事实和待确认项清楚 |
| 即梦或Seedance提示词 | 即梦分镜导演 | 浩辉短剧导演、生产资产台账 | 使用即梦格式并通过连续性校验 |
| MiniMax H3或Ref2VA提示词 | MiniMax H3分镜导演 | 浩辉短剧导演、生产资产台账 | 使用H3格式，不混入即梦语法 |
| Wan 3.0提示词 | Wan 3.0分镜导演 | 浩辉短剧导演、生产资产台账 | 只引用真实上传素材，使用Wan格式并通过素材真实性校验 |
| 检查生成视频、决定是否重跑 | 浩辉成片审片 | 对应平台分镜导演 | 带时间码证据、冻结项和最小修复卡 |
| BGM、环境声、动作声和声音桥 | 浩辉后期声音导演 | 浩辉成片审片 | 声音方案不遮挡对白并可执行 |

## 阶段门

### 剧本门

- 事件顺序、角色关系、对白版本和结尾结果已确认。
- 若用户只要诊断，不进入修改或分镜。

### 资产门

- 人物、服装状态、场景、关键道具和真实素材职责已明确。
- 用户负责资产制作时，只输出资产需求与编号，不擅自生成图片。

### 空间门

- 多人、固定座位、出入口和反打场景必须确认参考图是否锁定站位。
- 未确认时可以提供纯文本俯视图草案，但不能把草案写成最终左右位置。

### 平台门

- 明确即梦、H3或Wan 3.0后才进入对应适配器。
- 未指定平台时停在导演分镜，不猜平台参数。

### 审片门

- 必须取得实际视频或足够连续帧；只有首尾图时限制结论范围。
- 重跑只改失败层，成功层冻结。
