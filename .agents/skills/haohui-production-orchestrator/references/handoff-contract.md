# 跨模块交接契约

```text
【项目/集/场/镜】：稳定编号
【版本】：剧本、资产、空间、提示词、视频各自版本
【当前阶段】：
【上游输入】：文件或用户消息范围
【已锁定事实】：事件、人物、状态、场景、道具、空间、台词、声音限制
【待确认项】：只列会实质改变下游结果的问题
【本轮主Skill】：
【辅助Skill】：没有则写无
【本轮交付】：
【候选/选片状态】：候选／已选／拒绝／待确认
【事实来源】：直接观察／用户报告／计划状态／待确认
【计划镜尾】：
【实际镜尾】：仅已选片段进入连续性事实；尚未生成则写无
【镜头终点用途】：无缝续拍／下一镜切换／过桥／尾部修复／重新定场
【验收条件】：可观察、可核对
【下一处理方】：用户／即梦／H3／浩辉成片审片／浩辉后期声音导演
```

## 版本规则

- 不用“最新版”代替版本号；重要资产与提示词记录版本。
- 上游事实变化时，标记受影响的下游镜头，不默认全量重做。
- 审片通过的镜头被冻结；除非用户修改剧本或发现阻断错误，不回滚。
- 新生成文件默认只是候选；只有用户明确选中或接受后，实际镜尾才取代计划镜尾成为下游连续性依据。
- 事实必须注明是直接观察、用户报告还是计划状态；不得混写。
- 同一镜头在不同平台生成时使用不同平台版本，不共享专用字段。
