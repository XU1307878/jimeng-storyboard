# AI短剧Skill固定评测法

## 目的

用同一批任务检验升级是否真的改善路由、空间、表演和平台隔离，不比较固定措辞。

## 执行

1. 每个案例使用全新对话，提供 `request` 与 `fixture`，不提示预期答案。
2. 记录实际调用的主Skill和辅助Skill；不得一次加载所有影视Skill。
3. 对每条 `expected_invariants` 记 `1`（满足）或 `0`（不满足）。
4. 任一 `forbidden` 出现即记录阻断失败。
5. 同一版本至少跑两次，区分稳定问题与偶发生成差异。
6. 修改Skill时一次只改一个规则组，再用全部案例回归。

## 通过线

- 路由正确率100%。
- 无平台混写、剧情改写或未确认站位写死等阻断失败。
- 每个案例预期不变量至少80%满足。
- 新版本不得让已通过案例出现新的阻断失败。

评测结果应记录Skill提交号、模型、日期、案例ID、各项得分、失败证据和决定采取的单一改动。
